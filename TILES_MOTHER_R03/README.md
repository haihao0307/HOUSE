# Tiles Mother R03 / 09J — TLO 基础形体

本轮 2026-10-27 创建。在既有 HOUSE / R02 共享连续片上加最小 TLO 接口；不是另造瓦类系统，也不替换 09H 质量锚点或 09I 旧配方。固定基线 b51759ffb33ad3d12d31d9735f692527691cecb0。

Time 是对象记录创建日期。Location.site 默认昆明，只是地点标签，不参与求形。Object 引用确定版本的母体，保存 ID、size=[长,宽,厚]（米）和唯一新增形态标量 bend。局部原点固定为材料中心 u=0,t=.5,q=.5；x 横向、y 向上、z 纵向。位置/方向以后作为单独实例放置层；本轮不擅自添加。

形体从 TILES_MOTHER_R02/mother.cjs 的 base/normal/skin 零细节特例提炼到 shape.cjs；tlo.cjs 封装TLO，shape.cjs将 bend 映射到有符号弧高 rise=.45×width×bend。零弯曲精确回到长方体，正弯示范板瓦、负弯示范筒瓦。三档只改 bend，尺寸不偷偷变化。不宣称一个标量涵盖所有传统瓦，旧配方的小头、收分等仍保留在原09I固定链接。提炼只针对零细节基础片，不冒称完整R02能力被压缩。尺寸是函数试验值，不是昆明实物测量。宽度为基础片宽/上表面弦宽，本变形未证明弧长或泥坯体积守恒。

主形不保存顶点、三角形、点云或外部模型。共享母体与实例参数无显示依赖；新显示器直接对两圆柱边界、两侧界和两端面解析求交；GPU仅用全屏三角形作光栅载体，没有物体网格。WebGL不可用时CPU Worker逐像素解析求交，更新可取消、最新帧优先。支持各尺寸0.1–10000毫米；长宽厚比≤1000；曲率×厚度绝对值必须小于0.8。GPU求交局部坐标按最大尺寸归一化，真实参数不夹值。默认常量中性表面、造波强度零，专门验基础形状，不是删改旧材质。关于用谱/造波表达大形的新讨论等待用户公式，本轮不擅自实装或将造波永久限定为微细节。

体积由 BYTES.json 实测：纯核心依赖闭包包括提炼后的 shape.cjs 与本轮 TLO 接口；实例紧凑 JSON 单独计量；显示适配器与独立工作台另列。不能把引用字节数当作整个对象依赖成本。

运行：`node TILES_MOTHER_R03/build.cjs` 构建新09J独立HTML；核心测试见 tests/。本地浏览器启动因执行环境 socket 限制失败，云浏览器 file 协议不获允许。必须在本轮授权的固定 HTTPS 候选地址完成真实浏览器检查后才可交付；最终证据另附 PUBLICATION_PROOF.json，不能把发布前状态当完成。
