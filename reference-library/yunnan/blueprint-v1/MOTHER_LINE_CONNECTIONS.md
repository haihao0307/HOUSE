# 各专业与建筑蓝图的连接边界 V1

本文件记录用户已经确认的职责方向，以及本次整理形成的待对接字段。它不构成已实现、已测试或已获得专业线共同签认的运行接口。

## 1. 总体系与八个既有专业入口

沿用 PR #13 中八个模块 ID，不在这一轮另建生产线或替换旧模块。

| 入口 | 主要知识职责 | 与总体系的联系 |
|---|---|---|
| knowledge-blueprint | 案例身份、院落、间架、轴网、标高及证据关系 | 协调共同边界，保留专业冲突 |
| foundation-site | 场地、基础、地面、墙脚与柱础 | 分别核对墙和柱如何落地，记录局部地面基准 |
| timber-structure | 柱梁枋檩椽、构架与接合 | 使用对应案例的轴网和控制剖面，返回支承与连接问题 |
| roof-form | 主屋面、附属屋面、坡面与基层 | 明确承托、脊檐边界、坡向和排水目标 |
| tilework | 瓦件、铺设、搭接、脊檐与收边 | 与 Tiles Mother 的后续版本核对，并联系屋面承托 |
| walls | 墙体主体、砌筑、抹灰、洞口和墙顶收口 | 联系基础、木构、门窗及 Brick Mother |
| openings | 结构洞口、框、活动扇、枢轴及通行范围 | 区分洞口尺寸、框外尺寸和净通行尺寸 |
| timber-surface | 木材纹理、加工痕迹及表面状态 | 绑定同一具名木构件，不修改其轴线或接合关系 |

Brick Mother 是后续联系的砌筑单元专业线。这里不将它降为墙体内部实现，也不假定它已经接入墙体。Tiles Mother 与现有 tilework 入口的职责对应需要在取得其交接材料后逐项确认。木构和木纹分别保留来源、版本和验收状态。[U01][U05]

## 2. 共同记录的条件

每次将来接入需要记录：建筑与单体编号、目标年代、来源版本、原单位和换算、局部坐标方向、轴线、标高及地面基准、宿主部位、边界或支承、需要配合的接口、允许变动的项目、证据状态。

这些是待对接字段，不在本轮替各专业指定实际单位、坐标轴或允许误差。原单位和原坐标保留；转换关系另外记录。未知值为空，不能用零或习惯值伪装为已知。

## 3. 五组优先连接关系

门洞与墙体：洞口位置和边界、墙厚及收分、门框占位、侧壁、门头支承与抹灰收口分别记录。改变洞口后，需要协商受影响部位，不自动移动其他轴线来掩盖冲突。

石墙脚与土墙：两者交界线、局部地面、砌筑高度和原有接合做法一起核对。用户要求消除无依据的空隙属于当前参考墙的改进要求，真实存在的接缝或分层不得抹除。

木架与墙体：记录接触、嵌入、避让、支承或缝隙的案例证据。计算接触关系和真实受力角色分开，交汇位置不能充当完整榫卯或墙木节点的证明。

屋架、屋面与瓦作：屋架支承、檩椽位置、基层、瓦行方向、搭接、脊檐收口和水的去向保持可追溯。屋面形制及铺瓦组合由证据确定，不能由瓦母体任意反推整栋房屋类型。

构件与表面：单块材料的个体变化与整墙、整坡面的连续变化共同组织。微孔、纤维等尺度和构件总尺度分开。损伤、水痕或修补只在证据和项目允许的部位出现。

## 4. 接入状态分别确认

职责已知、资料已收到、版本已核对、接口已实现、接口已验证、视觉已批准和生产已批准分别记录。当前已确认的是整理方向及职责分工，实际跨母体接入、验证和视觉批准尚未由本轮完成。

建议的未来交接内容是：专业线现状说明、精确版本、输入与输出、参考材料和使用限制、具名样本、失败情况、尚未批准的项目。它是后续接入时的检查提纲，不要求用户现在补交材料，也不派发新的实施任务。

## 5. 冲突处理

先核对是不是同一建筑、同一部位、同一年代、同一测量口径；再区分实测、转述、图示、用户观察和模型需要。双方不能各改一个尺寸后宣告解决。解决记录写明所依据的资料、影响范围和复核人。

总体系负责协调，专业线继续保有自己的知识与版本。收集到更完整的资料后，先校准相应案例和接口，再讨论实施。
