# 建筑蓝图与总体系 V1

整理日期：2026年8月31日。项目：历史建筑生产线。仓库：haihao0307/HOUSE。

本版依据用户在本对话中的讲授、已确认的整理方向、原云南建筑系统，以及已经收存的文献支持记录编写。它是知识层的组织版本，不是建筑施工文件，不包含新生成器、默认尺寸或专业线接入实现。

阅读入口：[资料与案例对照](SOURCES_AND_CASES.md)、[专业连接边界](MOTHER_LINE_CONNECTIONS.md)、[结构化索引](knowledge-framework-v1.json)。

## 1. 总负责范围

本窗口负责建筑蓝图和整体知识关系。以具体建筑为中心，向上联系中国建筑术语及云南地方做法，向下联系间架、构件、材料、表面和历史状态。Brick Mother、Tiles Mother、墙体、木构、木纹及其他专业线各自深化，总体系协调它们共同依赖的条件。

这一认识继承旧系统的坊房、间架、柱网、院落、廊厦、独立屋面与分层构造主干。旧系统中的类型与参数仍需按原证据解释，本轮没有再次批准它们。[R01][R02][R03][U01]

## 2. 三层知识和两条贯穿线

共同术语层整理“怎样读建筑”：间、面阔、进深、构架、柱网、平立剖、台基、梁枋、檩椽、墙体、门窗和瓦作。它提供比较语言，不承担所有地方建筑的统一尺寸标准。

地方体系层记录某地区、年代和建造传统的具体做法。地点、建筑类型、匠作、材料、用途和居住者分别建档。民族名称、行政区划和形制名称保持各自来源，不由其中一项自动推出其他各项。

案例层保存具名建筑及具体调查状态。未知地点、年代、族属和隐蔽构造继续为空；扫描参考、文章案例和实测个案分开。相似名称只建立对照关系，不自动合并建筑身份。

证据和年代贯穿三层。每个结论都能找到提出者、具体来源位置、适用范围和未解决问题。建造时间、拍摄或测绘时间、修缮时间、目标表现时间分别记录。项目关注1940至1945年，当代调查不能自动证明该时期的状态。[R01][R04][R05][U02]

## 3. 建筑知识主干

沿用旧系统 L01 至 L14 的认识顺序：证据与年代，场地与主轴，院落拓扑，间架与柱网，地基与墙脚，一层平面，楼面与二层，立面等级，控制剖面，木构装配，屋面与瓦作，门窗运动，历史状态，三维装配与验收。[R01]

这是研究和核对的顺序。平面、剖面、构造和场地之间需要往返检查；目前不把它实现成强制运行流水线。

场地记录街巷、入口、局部地面与水的去向。院落记录房屋单元、庭院和边界之间的组合。单座房屋记录面阔分间与进深分段。柱网、楼面、墙体和屋架共同回答支承、标高和空间连接。屋面与瓦作回答坡面、承托、搭接、脊檐和排水。门窗与楼梯回答通行、开闭及其与围护构造的关系。

## 4. 间架、尺寸与图纸的整理口径

结构间数、实体隔出的房间数量、房间用途分别记录。面阔方向的轴距、进深方向的分段、柱数和构架榀数也分别记录。三开间与四条边界轴线的对应，保留为旧项目在规则框架下的表述；不能由此推定每条轴线上都有完整相同的构架或把所有地方术语强制统一。[R01][R03]

每项测量保留原文数值、单位、起终点、方向、轴线或净尺寸口径、原图页码和精度说明。米制换算另列，并记录换算依据。原单位“尺”缺乏明确制式时，不自行采用一个统一换算值。[U02]

平面、立面、剖面和节点图以同一案例及调查期关联。檐口高度、屋脊高度、层高、室内净高分开。控制剖面的构件关系与节点大样的接合细节分开。缺少尺寸不从透视照片猜出确定值。

## 5. 材料、砌筑、表面和风化的关联

根据用户的墙体讲授，墙体记录砌筑或夯筑主体、墙厚与收分、石墙脚、内外表面覆盖、洞口收口、与木架相邻关系、损伤和补抹。单块砖石形体与整墙砌筑不是同一个记录层级。[U03][R04]

“墙心”保留为用户对墙体主体控制的称呼。真实构造是否存在额外芯层，由原始资料说明；用于封闭显示的背板只记作模型辅助体，不能补写成历史材料。抹灰既可能连续覆盖，也可能局部缺失，实际覆盖范围和断口由对应参考判断。

土坯、夯土、烧结砖、砌筑石块、砌缝材料和抹灰分别认识。木框与墙体的支承或围护角色按案例核对，不把全部土墙统一标成无承重作用。稻草、稻壳、种粒等夹杂按用户的土坯研究方向保留；具体材料配方与地域普遍性仍待证据。[U03][U04]

材料本身、加工成型、安装部位、暴露与使用、损伤修补、可见表面形成一条研究关联链。它是本项目的组织方法，某处裂缝、水痕或变色的真实成因需要单独核验。

噪波只处理允许范围内的不规则表现。整墙连续变化、单块差异和微观颗粒纤维分层控制；结构轴网、洞口位置和材料身份不随表面种子变化。材料家族保持各自默认控制，构件尺寸与微观细节尺度分别记录。以上均为项目约束，尚未构成真实材料机制的独立验证。[U04]

## 6. 屋面、瓦作与木构的关系

先记录哪座房屋、哪片坡面、哪条檩线和承托，再记录瓦件、瓦列、搭接、边界、屋脊及檐口。旧知识中板瓦凹面、筒瓦盖缝、上段压下段及脊檐装配等内容，保留在原瓦作体系下并追溯原图版；不推定所有云南屋顶都使用同一种组合或都配置同样的檐端构件。[R03][R04]

木构关注构件身份、轴线、支承与接合。木纹关注同一根构件上的方向、加工痕迹及表面状态。外观侵蚀不自动变更结构连接。旧系统的具体楼梯跑数、固定交通路线、屋面限制等保留为相应案例或实现约束，不提升成通用建筑事实。[R03]

## 7. 近期资料在体系中的位置

文献登记表中九项来源保持既有类别，六项背景调查、两项方法支持、一项区域建筑参考。它们均不在本轮升级为生产依据。[R06]

白族 HBIM 论文第7至8页提供对象、属性、关系和装配方法的组织支持。合院数据库论文第8页提供环境、面积、高度、屋面与材料字段组织支持。生活调查补充房间使用、家族关系和后期变化。迪庆土司庄园补充具名地区和特殊建筑类型的对照。具体映射见资料对照表。[L01至L09]

来源原话、作者解释、图上可见内容、用户讲授、旧系统规则、本次整理建议分开。引用过同一篇论文的旧笔记和新笔记不能互相证明。用户允许收存，只说明资料可以保留。

## 8. 连接示例与未来接入

以参考墙的门洞为例：案例身份与调查期确定后，蓝图记录洞口边界、墙体位置和相邻轴线。墙体研究厚度、收分、侧壁和表面收口；门窗研究框、扇和开启；木构核对涉及的支承；Brick Mother提供已明确材料身份的单元。表面层只在各自部位内表现颜色与破损。实际尺寸或节点不明时，相关项保持待核。[U03][U05]

这段示例表达将来的协调关系，不表示本轮已经实施联动。专业线的当前版本、接入坐标与能力还需后续专门核验，不能从文件名推定最新状态。

## 9. 当前缺口与维护方式

最需要补齐的是具名案例完整平立剖、尺寸链、木构节点、墙体截面、瓦作铺设与收边、材料实物及其尺度、历史状态和维修记录。证据不足的地方继续保留问题，不填入貌似合理的默认值。

旧文件中可能存在过宽适用范围或过高证据等级；本版建立待核对照，原文件不被静默改写。出现新的可靠证据时，以单个结论或部位为单位复核，记录冲突、采用理由及被替代记录。可靠性根据所回答的问题判断，不能只用论文数量或机构名决定。[U02]

本版只新增知识文档和非运行索引。既有文献记录、原参考库、生成器、网页、材质和其他母体分支保持原状。人工视觉批准与生产批准继续为 false。
