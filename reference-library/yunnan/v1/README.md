# 云南民间建筑生产线参考资料总库 V1

本目录用于保存项目迄今收到并使用的参考资料原文件、现场照片、测绘图、科普图、反馈截图和知识提取文件。

## 使用规则

1. 每次建模或修改前，先读取 GitHub 知识库与本总库清单。
2. 测绘平面、尺寸链、控制剖面和明确节点优先于扫描外观与照片。
3. 照片和 GLB 用于综合色彩、粗糙度、风化、材料过渡和大尺度形态校准。
4. 重复文件保留用于追溯，证据计权只按规范图版或唯一哈希计算一次。
5. 资料可能包含第三方图版或网页截图，仅用于研究、证据追溯和项目生产，不主张原始版权。

## 覆盖范围

- 一颗印文章与科普截图。
- 刘致平 1940 年代昆明东北乡测绘图录。
- 平面、立面、剖面、门窗、砖瓦和屋脊图。
- 纳西民居类型图。
- 大理、乌龙村、团结乡三个 GLB 参考模型，模型文件已在 `assets/models/`。
- 2024 年现场航拍照片。
- 瓦、墙、土坯、抹灰、苔藓和风化局部照片。
- 网页问题和验收反馈截图。
- 建筑语法、构件模板和瓦作知识提取文件。

`REFERENCE_MANIFEST.json` 保存逐文件路径、字节数、SHA256、MIME 和证据规则。
