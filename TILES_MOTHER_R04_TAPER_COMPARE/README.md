## 小头是连续函数

`section.cjs` 是独立的 **598 字节**未压缩 JS 截面工具，不存点表。瓦长位置 `t∈[0,1]` 输入后，直接计算该处**宽度、弧高、抬升和厚度**。没有肩部时，两端变量按 `t` 连续插值；有肩部时，截面沿长度变化，再用三次平滑函数连续过渡到小头截面。肩部位置、过渡长度与四个截面变量都是显式参数。

R04 使用中面弧长作宽度；现有 R03 使用截面弦宽。A 在每个连续位置把弦宽转换为 R04 需要的角度和弧长，再真实调用 R04 的 JS 后端；B 用同一个变化截面工具沿直路径构造圆弧。两条都继续使用原 R03 的完整波场、形状扰动、边界/孔、压印、材料参考、颜色及粗糙度代码。B 目前是直路径、圆弧截面实现，**不是任意曲线路径与任意截面的通用扫掠器**。

## 直接显示与边界

网页的 CPU 工作线程对每个屏幕像素直接求连续形体函数的交点；没有物体网格或持久点阵。求交过程中会进行数值试算，这些试算点不是瓦片定义。`DIRECT_RAY_VALIDATION.json` 记录两条路线、四个观察方向、1,600 条朝向已知表面点的射线检查，未发现漏点；这不是任意视角、任意形制的证明。

直接求交目前计算较慢，预览宽度上限 200 像素，视觉清晰度不等于 09H。当前代码与采样核对只支持所列 R03 情况下的数值一致，不能把它写成全部瓦头、全部历史造型、整屋组合、09H 同机位视觉或所有参数的无损验收。09H 继续作为质量锚点；当前只交付用于看工具与关系的候选，不自动提升为新生产基线。
