# Tiles Mother R04 · 09M 三维连续曲面研究候选

09M 是单瓦与三片组合的交互研究，不是 09H 整屋替代或质量验收通过的生产基准。09H 仍是固定质量锚点；其原版、原始 R04 包和 09L 均未覆盖。主入口使用固定 HTTPS，历史版本链接保留。

## 规则与对象

沿用 R04 的 143 B GLSL 弯曲核心，`section.cjs`（598 B）连续计算宽度、弧高、升高及厚度，并平滑处理小头肩部。A 路线把弦宽转换为 R04 弧长后调用 R04；B 路线按直路径与变化圆弧截面计算。两个路线与共同材料坐标共同计算造波、位移、颜色与粗糙度；B 不是任意曲线路径或任意截面的通用扫掠器。原 R04 基础 4 个 float32 共 16 B，不包含小头、材质、身份或关系。

身份、母体版本哈希、归属、参考架、位置、旋转与关系分别记录。单瓦时间、地点未知为 null。组合是两片 L9 板瓦和一片 L9 筒瓦的合成演示，不是具体历史建筑；三片对象有不同种子和稳定身份，属于示例屋面。`PATCH_CONTACT.json` 与 `ASSEMBLY_VALIDATION.json` 保存本次数值范围。两侧各 97 个边缘投影查询的最近间距约 0.05 / 0.23 mm，最大约 4.92 / 5.27 mm；此外对覆盖区域进行 1,228 个投影查询，板瓦间距作 202 次边界查询。均为有限样本，**不证明连续贴合、防水、承重或施工**。

## 显示与体量

`SIZE_AUDIT.json` 是精确字节清单。两条路线的未压缩代码及共享配方闭包 A 18,245 B、B 17,881 B；独立后端对象关系执行器各 3,930 B。完整工作台 HTML 100,790 B，本机 gzip 后 28,543 B；实际网络传输编码可能不同。HTML 同时包含两条路线、图形计算、CPU 复算、界面和示例关系；它不是单片瓦数据。普通实例配方 JSON 203–505 B，另有材料参考及共用规则，不能把其字节数当成可独立运行的完整瓦。

三维画面直接查询连续函数的射线交点；全屏三角形用于屏幕计算，临时纹理只保存显示迭代状态，不是对象形体或持久点表。GPU 分批求解，孤立漏点、可疑深度及局部异常明暗只作为重新求交候选，CPU 必须对同一连续函数求得有效交点才改写画面。该方法是有限迭代，不保证任意参数及视角都找到了最近交点。640×480 的 25 层 RGBA32F 临时纹理约 122,880,000 B，驱动与 CPU 读回另计；缩小文件不代表运行内存自动变小。

## 本次核验与限制

记录见 `QA09M.json`。在本机浏览器中，两路线、四瓦型和四视角的 8,512 条选定射线经 CPU 双精度复核未发现未解决项；旧 CPU 求交在其中四条漏过更近的有效交点，已单独记录。94 组、6,016 个连续查询对照形体、材料位置、颜色、粗糙度、位移与微梯度，最大位置差约 18.1 微米。最初微梯度 0.00005 绝对阈值未通过，测得最大约 0.0000678；最终按造波强度使用 0.0001 倍数作为显示容差，不能称为逐位相同或所有条件无损。

32 组 640×480 指定画面中，按周围 7/8 像素已命中判定的孤立空点为零；另对 32 组 480×360 画面中的 509 个明暗异常候选做了数值求交复核，没有发现所测更近交点遗漏。以上都不是任意像素、角度或设备的证明。一次 640×480 本机单瓦测量首次约 1.22 s、三次热运行约 0.57–0.70 s；机器和浏览器不同结果会变化。图形上下文模拟中断后恢复并保留参数；390×844 是桌面浏览器 iframe 模拟，不是真机手机验收。

尚未迁移完整屋面、瓦当/滴水、木支承、折坡接触以及 09H 同相机同光照下的完整视觉与交互；页面的简化光照没有 09H 的完整阴影系统。L9/D7 以现有图示解释和假设为依据，不能声称是已实测的制造尺寸或现场工法。

## 本地源码文件

公网预览目录包含自含 HTML、尺寸和验证记录及规则原件；下列源码与可重跑检查保存在同一版本提交的 `TILES_MOTHER_R04_QUALITY_R05` 目录及本机同名目录。

- `build09m.cjs`：核对 R04 父版本哈希、组合报告后生成独立 HTML。
- `route-a.cjs` / `route-b.cjs`、`section.cjs`、`library.json`：两个函数路线与共同配方。
- `gpu-surface.glsl`、`shared-field.glsl`、`pass-*.glsl`、`gpu-renderer.js`、`direct-ray.cjs`：临时显示与按需复算。
- `patch-contact.cjs`、`verify-assembly.cjs`、`size-audit.cjs`：关系、坐标和体量检查。
- `build-batch-check.cjs`、`build-surface-validation.cjs`、`build-holes-check.cjs`、`build-dark-matrix.cjs`、`build-context-test.cjs` 与 `MOBILE_CHECK.html`：生成并运行本机浏览器 QA；输出只对应所列配置。

共同项目规则原件随版本保存：`MOTHER_OBJECT_DEFINITION_RULE_2026-09-09.md`、`MOTHER_PUBLIC_PREVIEW_DELIVERY_RULE_2026-09-08.md` 和 `TILES_MOTHER_CHARTER.md`。
