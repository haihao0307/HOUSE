# Tiles Mother 08D · 瓦面、边口与气孔

固定公网：https://raw.githack.com/haihao0307/HOUSE/d3f5a1fc7683daf9838f67957e55b549319a92ef/tiles-mother/r2-closeout-08d-relief/START_HERE.html

08D 直接修改几何而非仅修改控制 UI。原有 Microscope 17 层余弦核心经过不同尺度适配，形成宽尺度表面起伏、中尺度不平、稀疏有底凹坑；前口与侧边轮廓发生真实变化。侧壁凹坑同样进入几何。默认强度 1.6，底面位移固定为零。孔深、阈值和边口幅度是视觉适配参数，不是由截图测出的真实尺寸。没有将灰青基色替换成截图的红色。

单瓦采用 192×192 的临时显示采样，并提高厚度方向采样；屋面保持原 40×40 显示采样。二者使用同一形态函数与身份规则，小孔在远景屋面上会因采样较粗而损失细节。显示网格是可丢弃输出，不作为对象事实或精度证明。

法线根据变形后的局部切向更新，侧壁由实际三角面导数确定；原先较强的细纹法线响应减弱。PBR 色彩仍独立。

运行 `python build.py`，从 base-08C1.html 和 shape.glsl 生成自包含 START_HERE.html。使用 `node qa_geometry.cjs` 复查记录的代表接触。make_qa.py 是本机生成 QA 的辅助记录，接续无需运行它。

原版入口、SEATS、PROFILE、尺寸、宏观类别与排布不改写。包内携带 Mother 对象定义及固定公网交付规则。没有导入撤销的旧技能、隔离区内容、外部资产生产系统或原始大参考资产。
