## 2. 新情景合同

默认情景命名为“潮湿旧宅：持续失养约十年”。10年是用户指导的严重坍塌目标情景参数，不作为各地区、各木种、各初始状态的统一寿命。建筑本来年龄、停止维护时间、失养经过时间、修复事件和播放速度分开。空置但有人巡检修缮与完全无人维护可分别试验；occupied字段本身不参与腐朽公式。

主时间轴展示停止维护后的0至15年，重点按钮0/1/3/5/7/10/15，10年重点查看。阶段候选：0至2年局部漏水与积湿，2至5年漏点扩大、椽和横梁节点逐渐腐朽，5至8年局部支承失效，8至12年进入严重屋面坍塌。阶段用于组织镜头和调参，损伤通过连续状态和事件表达，不在第十年统一把所有物件隐藏。真实初况不同可改变过程；完整建筑坍塌还涉及墙/柱/连接，不能由Tiles单独宣称已经求解。

状态链条为瓦片裂缝/缺口、雨水进入、局部积湿、椽与横梁各自累计损伤、支承网络断开、所托瓦片/木段脱离、暴露区域增大。横梁独立接收渗水、直接暴露与节点积湿，不再必须等待椽loss先增大。局部噪波决定细节差异及阈值扰动，累积过程控制是否损坏；不每帧重新抽签。

木材损伤、表面发黑和失支分开。完整外观的木段也可能随下方支承失效脱离；颜色变黑也不能自动视为已经折断。所有依赖真实支点的对象统一传播状态，避免上面损毁后下层永久完整，或横梁已断而上层悬挂。恢复维护可减缓后续受水与损伤；断裂不能凭切换按钮自愈，只有明确补瓦/换椽/换梁事件可以换新，原事件账本保留。

当前 logic.mjs 只验证时钟分离、恒定区间积湿积分和有向支承图闭包。wetness、damage为无量纲显示状态，不是实测含水率、强度或截面损失。支承图的supported只表示依赖满足，接触、荷载与动态几何尚需独立检验。它没有模拟整屋面十年过程，候选速率也未标定。

## 4. 更好的裂口和厚苔表现

陶瓦：保持主体与边口；细裂以有方向、宽度、深度、分叉和终止位置的局部裂纹事件表达。Worley可用于分区或局部缺陷候选，避免整瓦变成均匀蜂窝。F2-F1不能直接当毫米等宽裂缝距离。贯穿裂缝、缺角与分离碎片需有真实断面、体积/厚度及支承变化，细纹颜色不能替代开口。

木材：借鉴SideFX木材破裂中的grain方向、横切、splinters与cluster概念，给沿纤维长裂、参差断口及残留木刺分别建可复核规则；不同材料的破裂不共用一张噪波图。方向用构件语义轴，不能盲用世界Y或最长包围盒。旧平面cap保留对照，先做一段椽和一段横梁的局部断口，不同时改整屋面。

青苔：分开湿度/遮蔽形成的生长候选场、覆盖率、厚度和粗糙外观。稀疏局部几何表达轮廓与体积，微细节由程序场表达；不直接给860片每片加多层透明外壳。宿主瓦片脱离时苔随宿主，碎片后续再决定保留/脱落，禁止苔悬在原坐标。照片继续只作观察依据，未量得苔厚或物种。

这些视觉方法尚未在本轮渲染或验收。

## 5. 纯噪波与性能路线

当前已是程序化工作台，包含解析噪波及程序生成的小型细节DataTexture。把小缓存全部替换成逐像素高层数噪波，收益未知。本轮不接入外部贴图、常驻扫描网格或新大模型，不改变现有固定几何、阴影和分辨率来假装提速。

优先试验为“共用字段、一次计算、多通道派生”：同一局部空间采样结果供颜色、粗糙度和法线等使用，参数通过uniform/实例属性改变。先检查编译后实际成本；不能仅按源码同名调用次数声称GPU做了同样次数的重复工作。稳定烧成变化在实例生成时得到；损伤变化只触发受影响节点/区段更新；GPU着色和CPU结构图互相分离，渲染帧不能驱动腐朽速率。

解析梯度候选：在同一次场评估中返回数值与导数，避免有限差分的多次完整评估。noise-gradient.mjs是本轮自写的三维cubic value noise，非Blender/SideFX实现，也未替换现有clayGradient的纹理梯度。256个采样与尺度链式法则测试通过，只证明该CPU数学核。中心值加三轴中央差分需要7次该核值评估，解析版只取一组8角点，不能由角点次数推出实际7倍提速。

比较两条候选：A保持当前程序细节缓存并共享结果；B保持可见尺度目标，使用有上限的纯计算噪波和解析梯度。两条均保留当前版回退。域扭曲加层有预算，Warp后的导数需要链式法则；标准二维表面域可节省计算，但端面/接缝/三维附着必须通过再采用。不用减少细节等级或动态LOD掩盖当前成本。子像素过滤属于以后单独评估的着色候选，不擅自改变已锁画面。

测量：固定seed、时间、相机、灯光、视口、网格与阴影；比较三片、48片、860片，分别记录首次CPU时间、切换/回看时间、编译次数、CPU/GPU帧时间、内存和视觉差异。GPU计时不可用时记unknown，不套用CPU耗时。继续检查6秒静止零新增绘制、三窗口运动及移动端；不承诺尚未测得的流畅度。
