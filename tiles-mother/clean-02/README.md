## 这轮范围

瓦片实体位置、厚度、模板种子与落座参数保持Clean01。原构造台人为少放的一片顶口筒瓦已补上：28板+21筒=49片，UI明确显示新数量。860片仍为440板+420筒。48是历史构造台称谓，内部兼容场景id仍为roof48，不混报数量。

色彩恢复明度、冷暖、整片差异、土赭、灰化、黄土胎、表面起伏；木纹有独立局部转向。瓦色改为低饱和中性灰底、较缓灰化过渡和少量土赭。数值是当前参考指导的展示配方，未经实物光谱标定。颜色变化不重建几何或换光照。

苔覆盖和体积厚度分开。局部湿区偏置在相邻瓦中关联，共同参与着色覆盖与局部几何出现的概率；几何是有界局部苔簇，未对每个像素的生长与几何轮廓作严格同场重建。覆盖参数可形成成片效果，年份只决定情景增长。苔宿主必须仍在役；新几何不使用矩形裁剪。未标定苔物种、真实厚度。

木材沿长度连续变细，完整横梁按真实情景损伤显示；存留木材按连续长度合并，停止逐排切成短棒。蚀薄网格保持原材内缩，轴向损伤和角向凹损变化。为守住当前静态落座，承托上弧及横梁接触处留承压带，状态失效时再移除。该近似不代表所有腐朽都从底面开始，不是截面强度计算或真实腐朽物理。破损面和整屋碎片坠落仍需后续完善。

复用原生渲染与静止停绘，无网络材质、UV展开或法线图片。函数导数、几何方向、阴影深度缓冲仍用于光照，不能称零GPU。色彩/木纹参数走uniform。无伤长木共享几何绘制，有腐朽的存留长度单独生成。
