# Macroscopic microscope R2 用户教学 · 核心一与核心二

来源日期：2026-09-06。来源：用户在 Brick Mother 会话中直接给出的公式、解释和推导。本副本放入 Tiles Mother 当前全量交接，只为后续接手稳定读取，不表示新增算法或人工批准。

## 核心一：对数球坐标

原作先把三维位置改写为对数球坐标：

`xi0 = log2(length(p)) - 2 - 0.3*t`

`xi1 = -p.z / length(p)`

`xi2 = atan(p.x, p.y)`

本线按用户给出的精确形式记录。`xi1` 不额外减一，`atan` 参数顺序不擅自交换。常数偏移会改变后续余弦相位，因此实现和测试必须保持同一约定。

`log2(length(p))` 把距离的乘法变化转成坐标中的加法移动。距离成倍变化以后，尺度层级在同一函数空间中连续推进。静态建筑材料以对象局部参考坐标输入，时间项默认冻结。相机只负责观察；相机位置、屏幕坐标、帧号和生成顺序不能进入材料身份。

## 核心二：十七个尺度及其导数意义

尺度为：`1, 2, 4, 8, ..., 65536`，共十七层。

单层主体：

`C_s(xi) = cos( cos(s*xi2)*cos(s*xi0) + cos(s*xi1)^2 + cos(s*xi1)*cos(s*xi0) )`

等价紧凑形式：

`cos(dot(cos(xi.zyy*s), cos(xi.xyx*s)))`

组合场为各层 `C_s / s` 的前缀和。新增层时保留旧层原系数，不按总层数重新归一化已有粗层。

每层数值幅度按 `1/s` 下降；对位置求导时，内部相位会带回频率因子 `s`。因此更细层对标量值的贡献可以很小，对梯度、边缘方向和法线的影响仍然明显。高频层需要独立屏幕足迹过滤、法线强度上限和抗混叠检查。

## Tiles Mother 直接落地约束

1. 当前 08A/08B 宏观瓦体和装配是保护基线；Microscope=0 时不得恢复任何旧刀刻纹或另一个新材质系统。
2. 粗层和中层可以组织瓦面可见的宽尺度起伏与色彩/粗糙度区域；细层主要贡献微形态、微法线与细粗糙度。
3. 用户现在要求 Microscope 不只影响 normal：08C 要让同一场进入瓦面与瓦边缘真实微形态。但大体尺寸、主要弧度、搭接和支承关系仍受保护；一旦真实顶点位移改变接触，必须重新做接触/穿透 QA。
4. 同一 tileId 的十七层前缀、局部坐标和相位保持稳定。换镜头、改变创建顺序或重新加载不能改变表面身份。
5. 不使用规则白点、规则黑点、棋盘、成组回旋线、刀刻线或每面单独随机制造复杂感。
6. PBR 仍是当前材质系统。用户要求 PBR 色彩调整拆成独立按钮/控制区；色彩丰富度参考讲武堂轻量证据，不从参考图虚构实测高度或粗糙度。
7. 瓦面域映射、幅度、边缘权重、抗混叠过滤、PBR 增益属于本项目适配参数；不得冒称为 Yohei 原作未核实的旋转节点常数或实测瓦片数据。
8. 正式候选固定相机、灯光、曝光、形体和种子，对比 Microscope=0、默认、增强；灰模看瓦面/边缘轮廓；PBR 色彩按钮单独开关；再跑屋面、年份、移动端和公网 QA。

当前用户方向：只做最后 08C 收尾，不再发散或重做工作台。
