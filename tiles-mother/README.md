# Tiles Mother V0.1

瓦片与瓷砖的独立程序化学习工作台，创建于 2026-08-31。该生产线长期负责屋面瓦、地砖、瓷砖及相关构件的资料研究、程序化生成、网页观察和版本维护。

## 当前交付

`index.html` 是自包含网页，没有外部脚本、字体或材质图片依赖。在提供 WebGL2 的现代浏览器中打开即可运行。首版有青灰板瓦、青灰筒瓦、素烧地砖、釉面瓷砖四个实验母体，每类可观察三个独立种子变体。

所有尺寸、色彩、弧度和风化预设都是待参考校准的实验值，尚未完成实物或历史复刻。

左侧选择母体、参数和独立种子；中间旋转、缩放、观察正反面和实体厚度；右侧拖入、粘贴或选择 PNG/JPEG/WebP 参考图，填写来源与观察笔记。参考照片用于研究，不贴到生成材质表面。

## 保存和协作

原图及笔记保存在当前浏览器的 IndexedDB，保存不可用时页面会明确提示。原图保持原始字节和尺寸。最多 40 张，每张不超过 30 MB，总量不超过 160 MB。

“保存协作记录”导出包含原图、笔记、参数、种子和 QA 的 JSON；“载入记录”恢复并合并参考图。没有云同步或自动识图。工作台里的资料不会自动进入聊天，需把原图或协作记录发回聊天中继续共同研究。清除浏览器数据会删除本地记录，应保留导出的协作记录。
