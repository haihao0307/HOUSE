# Tiles Mother V0.2

瓦片与瓷砖的独立程序化学习工作台，维护于 2026-08-31。工作分支：`feature/tiles-mother-v0.1-workbench`。

## 打开工作台

计划的稳定在线入口：<https://haihao0307.github.io/HOUSE/tiles-mother/>。以 `qa-v02/publication.json` 的实际 HTTP 回读与公开浏览器测试结果为发布依据。`index.html` 同时是自包含网页，内联全部模型读取与解码组件，不依赖外部 CDN。

## 参考资料

文件选择与拖放入口不限制扩展名。GLB、glTF、FBX、OBJ、STL、PLY、DAE、3MF 已接入三维参考预览。可旋转、缩放、平移、归位、放大观察、切换原材质／素模／网格并截图。参考窗口与程序化母体分离，导入资料不修改母体参数或几何。

PNG、JPEG、WebP、GIF、BMP、AVIF、SVG 等图片可按浏览器解码能力预览。PDF 可在新窗口打开；文本以不可执行的文字展示；常见音视频按浏览器能力播放。其他格式完整收存，不把成功接收误报成成功解析。FBX 及其他格式的实际兼容性仍取决于文件版本、编码和配套资源。

支持多文件、整文件夹以及 ZIP。路径与原包保留；GLTF 的 BIN、OBJ 的 MTL、FBX 等模型的外置贴图应一起提供。缺失或重名资源明确提示，不自动向不可信外部地址发送请求。加密包、ZIP64、异常路径和过量展开归档保留原包并提示。

安全上限：单文件 512 MB、单次 ZIP 展开总量 768 MB、本地资料合计 2 GB、最多 2000 份。大文件是否能流畅预览还受浏览器内存和显卡限制。

## 原文件、笔记与协作

原文件以 Blob 写入当前浏览器 IndexedDB，保留原始字节、文件名、相对路径与 SHA256。参考图片不缩小。保存失败会明确显示暂留内存。清除浏览器数据会清除本地资料。

“保存协作包”导出 ZIP，包含原始资料、来源笔记、母体参数、种子和校验清单；“载入记录”校验并恢复。兼容旧 V0.1 JSON 协作记录。网页没有自动云同步，拖入的文件不会自动进入聊天；需把原文件或协作包发回聊天共同研究。

## 程序化母体

板瓦、筒瓦、素烧地砖、釉面瓷砖的 V0.1 程序化生成内核保持不变。各母体独立参数及种子。尺寸、色彩和风化都是待实物参考校准的预设。

来源知识包：`PROCEDURAL_FIELD_KNOWLEDGE_MINI_V1.0_2026-08-30`。沿用 Brick Mother 的多尺度字段、独立种子、母体隔离和人工批准原则。
