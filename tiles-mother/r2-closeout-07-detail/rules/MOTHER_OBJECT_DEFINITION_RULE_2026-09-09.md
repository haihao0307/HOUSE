# Mother 对象定义与工具边界

用户明确要求，2026-09-09。适用于全部 Mother、新任务、接续与后续交接。

## 工具边界

已撤销的旧图像转三维技能、其上游副本和旧资产生产技能不得调用、恢复、重新安装或通过另一技能间接引入。旧会话、旧列表、旧模板和历史包不是继续使用的授权。不得改名包装旧流程冒充本体系新工具。清理未完成前暂停新的资产生产和工具重建。

## 对象的持久定义

1. 身份、类别、版本和证据先于图形输出。来源不足时记为未知。
2. 测量必须声明参考架、单位、基准、测量方式、误差和来源。“绝对位置”只能指明确参考架中的位置，不得把局部坐标当作世界坐标。
3. 点、轴、方向、边界和相对位置明确表达左/右、前/后、上/下关系；不同对象间的坐标经明确变换组合，禁止独立缩放后冒充同尺度。
4. 组成归属、坐标父架、类别和实际连接分别表达。枪体与支架等对象必须记录相接的两方、各自连接点、接触区域、允许的相对状态和证据；仅写一个父子名称不代表已经连接。
5. 形状由直线、圆、圆弧和有边界的曲线曲面及其约束定义；保留决定形状的必要控制量，不把大规模面列表当作对象知识。复杂形状需要更多证据时，不强行归成几个简单形状。
6. 运行时为显示临时生成的面和其他缓冲是可丢弃输出，不能成为持久事实、精度证明或质量目标。文件传输量、解析后显示量与对象知识量应分别计量。
7. 材料、标记、声音和动作须关联对象、位置、状态和条件。连接中断、路径悬空、来源不明的动作或声源均不能靠画面遮盖。
8. 验收先检查身份、坐标、连接与边界逻辑，再看外观。原件已确认的细节要有逐项保留证据，不让用户替执行者发现基础逻辑错误。

## 执行顺序

先清理旧入口、默认提示、依赖和恢复路径，记录真实残留与阻碍；再建立本体系自己的测量与关系工具。清理记录不是新工具实现，也不代表新一轮模型已完成。

继续遵守固定版本公网交付与相机对照规则。已固定发布的历史产物不因同步规则而改写；历史资料不自动进入当前执行环境。
