# USER DECISIONS

## 结构和物理

- 板瓦、筒瓦必须真实搭接，不穿透、不悬空。
- 共享圆椽位于四根横梁上；板瓦与筒瓦的支承逻辑必须保留。
- 10年失修时中央区域已经大面积塌掉。周边、角部可以残留一些仍有支承的瓦和碎残关系，形成不规则犬牙边缘。
- 无支承构件必须退出在役位置，不允许画面中“浮着”。
- 木构损坏必须连续发展，拒绝刀切式突然截断。

## 色彩和材质

- 云南灰瓦总体偏灰、偏冷灰。
- 不用一个全局“冷灰/暖灰”旋钮给整屋统一漂色。
- 需要恢复一片一片之间的窑色差与老化差异。
- 灰化覆盖保留。
- 黄土胎只在真实破损/断面处显露。
- 湿润外观与雨水、积水和暴露关系绑定。
- 314159 当前质感作为视觉锚点，禁止无理由重做。

## Macroscopic microscope R2

- 技能必须能在画面上指出具体作用位置，不能只存在数学代码里。
- 表面起伏、边口细部、断面组织、木纤维和苔藓团簇都可以借鉴跨尺度方法，但每种材料有自己的结构解释。
- 微细节可以影响表面方向/粗糙响应；真实断边、厚苔、掉块、支承失效必须由几何或明确状态承载。
- 新增 R2 细节不得改变已正确的主体瓦形、安装关系和主色。

## 苔藓

- 成团、成坨出现的方向正确。
- 尺度跨度要更大，从小团到大片团簇。
- 优先发生在湿润、背阴、粗糙滞水、缝边、漏水等合理位置。
- 年份与持续漏水提高覆盖概率和尺度。
