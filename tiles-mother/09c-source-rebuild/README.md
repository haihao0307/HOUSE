# Tiles Mother 09C · 逐图构造修订

09C 是对用户拒绝的 09B 的修订，尚未经用户视觉接受。08D、09、09A、09B 的固定入口及源文件保持原状。

## 本次改动

- 两种滴水：板瓦最后24毫米连续过渡到各自滴水上边界；去除多余尖角。载瓦与纹饰面是同一闭合边界，内部重复盖面已去除。
- 木纹：恢复用户刚打开09时的轴向材质场；颜色与小幅几何起伏沿同一局部木纹参考架计算。PBR母体快照保留，未替换成另一套暖色预设。
- 图7六种梁架分别登记图面柱、梁、短柱和檩；图8游椿的云形撑、上枕、撑枕、三道梁枋墨线分别建模。
- L4/L5三种住宅剖面：保留各自柱位、楼层、开口、挑檐和分段举高。倒八尺中柱错误已去除，耳房后部由图示墙体承托。
- 檩、椽、瓦以同一截面基准组装；统一48毫米显示椽径，避免45/48毫米混用。顺坡搭接由实际三角面计算，平面分段不缩放瓦长。
- 正脊眼子瓦改为沿脊向的空心构件，花脊墨线取自L7透视区域。墙码头改为砖框填土；小丁走保留“不用泥巴”的独立条目。
- D7无纹圆瓦当增加斜端面与连续端身连接；27.8厘米总长、12.3厘米直径、11厘米投影高度、1厘米端板厚进入显示构造。23.2/19.8厘米的标注端点仍待核。

## 原图与证据

references 中保留11张用户原图，sources.json记录原文件名和SHA256。L9副本与L9哈希相同，不计为独立证据。L8包含原书图7、图8，不能把文件序号当原书图号。原书版次、现场误差尚未知。

图面轮廓、明确尺寸、推读与显示参数分别记录于 source_observations09c.json、SOURCE_ROOFS09C_OBSERVATIONS.json 和每个对象的导出定义。0.8米进深、未标截面、屋面灰座、挂瓦条、背面及浮雕深度均非现场测量。

## 未完成的证据范围

本版不是全部资料的精确三维复刻。D4/D6的不可见节点与进深、L7岔脊/四平脊/螺蛳脊的真实曲面及接头、脊兽背面和圆雕深度、完整榫卯仍未确定。原图墨线不等于历史颜料色，也不证明雕刻深度。数值接触不证明结构安全、排水、耐候或完整建筑平面。

## 构建

入口 START_HERE.html 是完整打包页面。python build09c.py 按保留的08D与09A基底构建09B基础层，再加入09C修订。依赖本地历史基底，不能宣称这些构建脚本独立自足。离线打开成品不要求构建。

roof_seats09c.json 为默认起伏参数的计算缓存；改变形态参数会重新计算。SOURCE_GEOMETRY09C.json记录逐项坐标有限性、屋面端点与瓦搭接验算，不能当成完整历史或构件碰撞验证。

网页交付须以PUBLISH_RECEIPT.json中的固定公网HTTPS入口为主，并实际浏览验收。附带两份Mother共同规则，继续约束后续版本。
