# 用户已确定的继承规则

三片独立瓦是主体入口，保留板瓦三片、筒瓦三片及板筒组合。48片台为24板瓦加24筒瓦；大屋面为440板瓦加420筒瓦。48片台沿四道板瓦槽配置五根共享圆椽，860片台沿22道板瓦槽配置23根共享圆椽。圆椽下方均有四根较粗横梁。

每片板瓦左右两侧落在相邻圆椽上，内部每根圆椽同时承托左右两片板瓦。筒瓦盖缝，必须贴靠左右板瓦。板瓦搭接不能穿透，完整瓦不能浮空；失去双侧支点时需要记录失去支承。没有木板、望板、挡雨板、连续底板或隐藏承托平面。

UV检查覆盖板瓦、筒瓦全部表面，以及椽子和横梁侧壁、端面和破损端面。程序化材质保持用户认可的V0.9.7骨架，避免灯光与材质同时修改。手工不齐、崩边、微孔和浅划痕应有分尺度关系。

整片瓦具有自己的烧成偏色。约24%采用讲武堂参考方向，深蓝灰27%、青灰25%、浅灰10%、白化7%、黄褐5%、铁红2%。这些是用户指导下的工作概率，合计100%，并非文物实测统计；单屋面实际抽样数会随种子变化。不能用一片瓦内色斑面积代替屋面瓦片数量概率。

雨水由缺瓦与开裂处进入；受水椽子逐段发黑、变细、下挠、断裂；瓦失去支点后破损扩大；更后期横梁可断。有人维护与停止维护使用相同初始条件对照，维修中断病害扩散。不可把经验年份阈值解释为全国统一寿命或结构安全结论。

所有批准字段维持false，等待用户明确视觉验收；“有进步”不自动转为本版生产批准。不得再把失败的旧材质、旧底板和旧工作台覆盖回来。
