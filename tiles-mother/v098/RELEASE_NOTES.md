# 本轮复盘与修正

上轮把“UV数值存在”和“真实构造成立”混在了同一条通过结论里。瓦片的静态检查无法覆盖椽子的侧壁朝向，更无法证明安装后没有穿透或浮空。

实际回读源码发现：圆椽缺少UV属性，侧壁三角形朝内；板瓦的横向间距小于含厚度的真实外廓；筒瓦用了固定高度；板瓦背面沿高频微孔法线偏移，会发生局部折返。修正后，以宏观弧形法线生成实体厚度，微孔质感继续由原有细节函数与着色器负责。

安装环节使用实际网格的下表面与支承上表面求交接触。先计算共享圆椽，再安放板瓦，最后把筒瓦放到两侧板瓦上。纵向搭接允许轻微安装倾角，禁止互相穿透。四十八片场景为保留24板瓦与24筒瓦，将筒瓦分配到三条内缝、每缝八片，避免将第24片筒瓦放到单边无支承的外缘。

新增四根横梁，并检查圆椽与横梁的有限宽度接触。木构侧壁使用沿轴向的V坐标，端面独立使用横截面UV。破损端面的顶点与侧面断口环共用相同空间位置，防止封口与外壳脱开。两端分别使用朝外观察的坐标方向，并用有符号UV面积检查镜像；故意镜像端面、反转侧面和压扁UV的反例均能被检查程序识别。弯曲木材的外向判据按局部中心线的径向符号判断，保留具体最小点积，避免误把倾斜法线当成翻面。

停止维护时，暴露部位会增湿、发黑、截面减小，出现下挠和中间断段。横梁后续进入病害。缺失支点会传递到瓦片落座判断，无法稳定落座的瓦不继续悬在空中。该演示仍含经验阈值，未声称是实测建筑的寿命预测。

本轮没有重新生成一套材质去替换被认可的瓦。三项关键生成函数已逐字节校验相同。整片偏色通过独立实例颜色乘数接入，在屋面层面统计比例。色族概率合计100%，没有拿一片瓦内部的颜色面积冒充整屋面的瓦片概率。

后续每次提交都应同时查看独立瓦、48片、860片、底面、断椽状态和木构UV。数值测试、程序化材质验证与人工视觉认可分别记录。任何一项自动通过都不替代用户视觉批准。
