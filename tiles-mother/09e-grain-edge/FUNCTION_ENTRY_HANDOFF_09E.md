# Tiles Mother 09E — 连续木纹与滴水满面纹饰

本版从固定09D独立生成，保留09D与更早版本入口。

- 两种滴水保留09D已认可的外轮廓和正面连接拓扑。原图纹线按横向位置、截面上下边界比例映射到整个正面，属于纹饰适配，不是新的测绘结论。
- 木材保留构件长轴/曲梁弧长坐标与端面分类。移除高种子偏移下的碎噪点配方，使用缓慢弯曲的长纹、宽色带、稳定构件色差；Microscope控制连续细节与粗糙度，粗层实际位移限幅0.45毫米，端部与榫眼淡出规则保留。
- 这是根据用户反馈重新调制的显示材料，不宣称与08D逐像素相同，也不代表已鉴定木材种类、历史原色或实物表面。
- 其他构件形态、布局和砖材沿用09D。09D的材料说明和检查记录作为历史文件保留，不应当作09E新材质的验证报告。

## 检查

`CHANGE_SCOPE09E.json` 核对两种滴水轮廓和拓扑未变、纹饰已适配，以及木材各向异性和位移限幅。
`GEOMETRY09E.json` 检查木材坐标、曲梁封闭与砖体。
`DETAIL_GEOMETRY_QA.json` 检查五种压印表面和连接载体的闭合性。
`LOCAL_BROWSER09E.json` / `PUBLIC_BROWSER09E.json` 记录实际浏览器检查范围。

可重建入口：`python build09e.py`，需要同级固定09D目录。原图、既有曲线以及基础构件函数保持来源边界。运行时网格为临时输出，曲线、坐标、测量状态及连接规则为定义。

必须继续携带并遵守本目录的 MOTHER_OBJECT_DEFINITION_RULE_2026-09-09.md 与 MOTHER_PUBLIC_PREVIEW_DELIVERY_RULE_2026-09-08.md。最终主入口必须是固定版本公网HTTPS，实际浏览器检查通过后才能标记交付。
