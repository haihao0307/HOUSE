## 有效 UV 区域方法

依据 FBX 实际三角形 UV，在每张贴图的原始像素分辨率生成三角形覆盖计数图：`U → X`，`V → Y` 使用 `y=(1-V)*(H-1)`；像素中心按整数像素坐标采样。有效区域是覆盖计数大于 0 的并集。

- 不使用报告缩略图；不扩张、腐蚀、填充、修补或从 alpha 推断有效范围。
- UV 越界顶点：0；带越界顶点的三角形：0。
- Diffuse：`30,432,933 / 49,000,000 = 62.1080265%` 有效像素；`18,567,067` 个像素排除。
- Normal：`3,879,676 / 6,250,000 = 62.074816%` 有效像素；`2,370,324` 个像素排除。
- 两张贴图的原生像素覆盖最大计数均为 1，重叠有效像素比例为 0；这只说明原生纹理像素没有重复覆盖，不否定真实几何的搭接。
- Diffuse 是 RGBA，但全图无 alpha=0 像素，有效区 100% alpha=255；无效区也主要是不透明像素。因此黑/暗色无效区不能按透明瓦面计入，且本分析将其完全排除。
- Normal 是 RGB、无 alpha；覆盖外不参与法线统计。

## Normal 有效区域复核

基准色定义为原始 RGB `[128,128,255]`。容差定义为每个通道分别满足 `abs(channel-baseline) <= N`。

| 范围 | 有效像素数 | 精确基准色 | ±1 通道容差 | ±2 通道容差 |
|---|---:|---:|---:|---:|
| 全图 2500×2500 | 6,250,000 | 6,170,135 / 98.722160% | 6,214,843 / 99.437488% | 6,223,286 / 99.572576% |
| FBX UV 有效区 | 3,879,676 | 3,853,421 / 99.323268% | 3,865,317 / 99.629892% | 3,866,803 / 99.668194% |

有效区内，按 RGB 0..255 → 有符号 -1..1 的切线法线假设解码，均值约 `(0.003920, 0.004120, 0.999927)`；中位数和 P95 偏转约 `0.317752°`，P99 亦为 `0.317752°`，最大值 `115.139°` 来自极少数非基准像素。0.317752°主要是 `[128,128,255]` 这种 8-bit 编码基准相对理想 `(0,0,1)` 的量化偏差，不能解释成真实表面坡度。没有由此生成高度或物理凹凸。

## Diffuse 有效区颜色和尺度

有效 UV 区像素均值 RGB 为 `(88.776, 78.941, 71.980)`，标准差 `(45.115, 44.345, 48.085)`；sRGB 代码值亮度分段为：暗 `<48` 占 `26.9080%`，中暗 `48..128` 占 `56.0484%`，中亮 `128..192` 占 `17.0435%`，亮 `>=192` 仅 `0.0001%`。

以 `R-B > 8`、`abs(R-B) <= 8`、`R-B < -8` 作为明确阈值的图像色彩候选分组：暖候选 `56.0008%`，中性候选 `32.5225%`，冷候选 `11.4767%`。这些是 RGB 图像分组，不是材质温度。

原生分辨率块均值变化：8 px 块 X/Y 邻差约 `7.542/8.016`，32 px 块约 `10.688/13.017`，128 px 块约 `16.796/24.416`。单像素有效邻域梯度 X/Y 为 `4.361/4.457`，X/Y 比 `0.9786`。这支持记录“多尺度斑驳/区域差异候选”，但不能把 32 或 128 px 直接换算成毫米，也不能把图像 Y 方向差异命名为制造方向。

为减少 UV 拉伸影响，又按每个 FBX 三角形的 3D 面积给 UV 中心采样加权：9,508 个三角形，总权重 `1,860.004007` 个文件单位²；加权均值 RGB 为 `(88.989, 79.222, 72.273)`。这是三角形中心近似，不是逐像素曲面积分。

Diffuse 中的暗部、边缘高亮、遮蔽和反光可能已经烘入贴图；当前包没有可靠证据把它们与真实基础色分离，因此只记录为观察/未知，不恢复“真实 base color”，不填写粗糙度。

## 瓦型结论

实际 FBX 只有一个名为 `01` 的合并对象，`.rsInfo` 的 `tileType="0"` 没有可验证语义字典。四视图显示一个包含重复平缓曲面与弧面结构的合并瓦面阵列；“板瓦/筒瓦混排”只作为视觉推断标签，板瓦、筒瓦以及用户称作“顶瓦”的精确边界仍未知，不能强行命名或计数。
