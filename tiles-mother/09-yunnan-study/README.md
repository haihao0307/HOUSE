# Tiles Mother 09 · 云南图纸重建研究版

2026-10-24。接续08D，独立版本；不改写已接受的08D入口。

本版把用户提供的10张独立图纸组织成38个可旋转的三维研究条目，包含两套单瓦规格、13件纹饰/脊饰的轮廓深度示意、屋面/脊部/木瓦连接、砖作及3个住宅断面的空间化。**不是全部构件严格尺寸复刻的完成版。**

## 已实现及证据边界

- 筒瓦由主体、小头、肩部和连续内外壳组成。D7默认暂将22.2 cm解释为主体长、另加3.2 cm小头；界面可切换成总长解释。宽度11.5/9 cm。截面半椭圆是重建假设，不是原图测得的曲线。H1经局部放大由旧暂读5.5更正为暂读3.5 cm，仍保留释读状态。
- 板瓦D7：长23.8、宽24.2/22.1、弧高5、厚1.2 cm。L9：长24、宽21/19、厚1.4 cm。两组不混用；L9弧高4.5 cm只是显示参数。
- L9筒瓦24 cm默认作为含小头总长；12.5 cm大口宽来自图示，颈段3 cm、截面高及厚度没有图示证据，标为假设。
- 圆端直径12.3 cm已进入模型；27.8/23.2/19.8、11及1 cm的侧图标注已保留，但侧图端点与圆端倾角未解。当前端身模型不能通过整件尺寸验收。
- 图录纹线保存在source-curves.json，具有来源图、像素区域和简化方法；较大的脊饰另有人工勾画边界以排除邻近文字。它们是线稿轮廓的挤出与描线，**不是原件圆雕或浮雕的真实复原**。内孔是否穿透、背部和深度未知。宽度/深度/凸起中的显示假设均显式保存。
- 砖的图示尺寸及住宅主要标注另列在界面。住宅仅为空间化横断面；0.8 m横向深度是观察参数，不能当作完整建筑或真实开间。
- 屋面、脊部、梁檩椽关系均为研究布局。接触、灰泥垫层、榫卯、排水和受力未验证；不继承08D的SEATS结论。分层展开只帮助观察。

## 文件与对象规则

START_HERE.html为独立WebGL2工作台，references/为用户提供的参考图（转发图，不冒充已核验原版）。study.js保存曲面与组合规则；OBJECT_DEFINITIONS.json保存对象、参考架、变换、曲线/体素参数及未知项，不保存三角面列表。渲染网格临时生成。

build_study.py从08D的渲染器和本目录规则生成页面，不调用已撤销的图像转三维或旧资产技能。使用独立新目录，未引入历史恢复入口。两个共同规则原件随版携带。08D页面链接保留于工作台内。

构建：`python build_study.py`；几何检查：`node qa.cjs`；浏览器检查：`node browser_qa.cjs [公网URL]`。本机运行时路径见测试脚本，部署页面无需这些依赖。
