# Tiles Mother V0.9.11 共用噪波场与断口工作台

这是在V0.9.10之上追加的可交互候选，保留三片、48片、860片以及旧材质对照。打开START_HERE.html即可运行，Three.js运行库内置；不需要联网取得扫描模型或外部材质贴图。

## 观察方法

默认进入“噪波与断口样台”，年份为停止维护经过8年。右侧可以单独看瓦断口或木断口，调整受水倍率、样台荷载倍率、断口检查展开，以及厚苔开关和厚度。底部时间轴从0到15年。D切换新程序材质与上一版表面；A/B/C继续保留原形及原材质比较。

在三片页比较细孔、色层和边口，在48片页看第7与10年的上下木构变化与底面，在860片页看完整屋面与严重失养候选。标为“持续修缮”的按钮重新选择从初始状态一直修缮的对照情景，不表示对已损坏的当前屋面执行一次修复。中途恢复维护和构件替换事件账本仍待实现。

断口展开是检查用的分离视图，不是重力坠落。样台采用均布荷载下简支梁/条带弯曲近似及候选受水强度衰减，数值1是本示意模型的触发阈值。整屋面仍使用曝光、含水状态与支承依赖的经验演化，未进行全屋有限元、曲壳断裂或刚体碰撞求解。十年是用户指定的严重失养情景目标，未据此推定普遍寿命或实际结构安全。

## 模块与重建

source/field_model.js：确定性的局部受水、候选损伤、简化样台受力和失养屋面状态。
source/wave_material.js：局部三维噪波及解析梯度，同一组采样驱动新材质颜色、粗糙度与法线；独立木纹和厚苔着色。
source/field_geometry.js：具有真实厚度的瓦片断面、沿木轴参差的断口、贴附宿主的有限厚苔几何。
source/field_ui.js：场景、失养时间、材料切换和最新请求优先的更新队列。
source/app.js及START_HERE.html由tools/build.py生成。修改模块后重建，不只改交付HTML。

在完整包根目录执行：

```sh
python tiles-mother/v0911/tools/build.py
node tiles-mother/v0911/qa/geometry.cjs
python tiles-mother/v0911/qa/browser.py
python tiles-mother/v0911/qa/performance.py
```

重建需相邻冻结v0910；Node几何检查需相邻v098中的内置运行库；浏览器检查需Playwright1.57.0、Pillow和Chromium。tools/refine_visible.py和tools/final_checks_patch.py记录本轮一次性迭代，已物化后的正常重建不需要重跑。transport仅记录最初7个源码的恢复入口，不能拿旧传输包覆盖以后修订。

## 范围与证据

本目录DELIVERY_STATUS.md和qa内原始报告给出实际运行范围与性能结果。旧版本的几何、陶瓦核心、细节函数和观察光保留；新D材质有意改变外观，可同机位比较。新材质包含按屏幕采样足迹抑制小于像素的高频分量，目的包括减轻闪烁和无效计算；没有宣称画面与旧材质逐像素相等。

新材料路径不采样外部材质贴图。整个工作台仍保留程序生成环境反射、UV诊断图和旧材质恢复缓存，因此不称整个应用绝对零纹理。厚苔的明显厚度和真实断面仍由几何承担，底层仍由WebGL三角形管线显示。

用户提供的讲武堂资料仅作为观察、蒸馏与对照来源，原ZIP、FBX和完整贴图不随本包公开。木纹、裂缝方向、苔厚和强度等候选参数仍需进一步实物/照片约束。当前visualApproved=false，productionApproved=false，publicSiteDeployed=false。
