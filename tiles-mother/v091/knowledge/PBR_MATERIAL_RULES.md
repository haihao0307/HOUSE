# Tiles Mother PBR 材质规则

本版本采用金属度与粗糙度工作流，并将烧制陶瓦视为非金属绝缘体。

## 通道职责

- Base Color：保存陶土与烧制产生的可见反射色，不烘焙大范围灯光和环境遮蔽。
- Metallic：陶瓦保持 0。
- Roughness：表达微表面方向分布、干湿、颗粒、磨损和风化状态。
- AO：单独保存缝隙和凹处的环境光可达性，不压制镜面贡献。
- Height：负责拍打起伏、翘曲、鼓泡塌陷、孔窝及轮廓级形态。
- Normal：负责砂粒、针孔、细刮痕及其他高频细节。

## 色彩空间

- Base Color 使用 sRGB 解释。
- Roughness、Metallic、AO、Height 和 Normal 属于数据通道，使用线性解释。

## 几何和微表面

实时位移层减少高频噪声，保留能够改变轮廓和受光转折的中低频形态。高频表面信息由法线和粗糙度承担。

## 正反面与侧边

正面、背面和断面来自同一烧制陶土实体，共享基础陶土色场。差异由暴露、积灰、受雨、遮蔽、磨损和破损历史产生。每类面拥有独立、外向的法线和切线框架。

## 时间演化

时间范围为 0 至 150 年。落灰、冲刷、烟熏、边缘磨圆、局部崩损和生物附着均采用受位置、遮蔽、坡向、排水和暴露控制的过程遮罩，避免无因果的均匀撒点。
