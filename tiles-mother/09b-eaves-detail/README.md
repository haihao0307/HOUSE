## 本版变化

- 筒瓦/板瓦、瓦当/滴水、脊饰分别同屏。瓦体保留08D曲面与独立小头，全部外面、内面、侧边和端面使用较弱连续位移。
- 三种勾头连筒瓦，两种滴水连板瓦；端面与载瓦为一个闭合边界，接合区移除内部盖面。浮雕按来源纹线形成连续高度面，未把墨线变成悬浮泥条。背面、雕刻深度仍未测。
- 圆钱作为独立椽头护面，保留放射花瓣、外圈回纹、中心真孔和钉。13 cm独立展示直径、孔径、钉长均为显示参数；组合檐口按椽径缩放。防护不等于保证永不受风雨侵蚀。
- 默认无望板，可切换望板；挂瓦条、局部灰座、连续灰背属于明确的构造假设。灰座贴合原板瓦底部，不替换原瓦。
- 木材继续使用保留PBR母体，原粗/中纹理与裂纹场也进入几何位移，端部和接头周边收敛。浏览器中原GLSL场读回后采样；不以无GPU的Node分支证明该效果。
- 工字墙加入5 mm灰缝、1 mm收进作为用户要求的研究变体；它不能覆盖L9“小丁走”旁“不用泥巴”的图注。
- 新增L8图7六种梁架、图8游椿，共49目录条目。以源图面观察坐标保存柱、梁、檩、短柱、屋面线与游椿外形。三柱七桁图当前仅定位六个明确圆截面，第七处不造假；原题保留并注明缺口。
- 游椿三道梁枋面保留原图墨线，梁端按图观察成形。门洞中的独立彩画样式只作独立来源展示，不拼成一扇门；黑色是图纸墨线，不宣称原作颜色。原图注明格子门已拆除。
