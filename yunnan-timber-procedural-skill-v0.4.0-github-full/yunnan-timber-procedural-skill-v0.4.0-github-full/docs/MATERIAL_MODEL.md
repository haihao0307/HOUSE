# 程序木材材质模型

## 颜色

大尺度颜色由深色、中色、浅色和风化色混合。纹理对比只控制色彩变化幅度。细节清晰度主要来自微法线、粗糙度与凹腔受光。

## 纵向纤维

纤维由三层不同频率的细长噪声组成。圆材分支提高纵向纤维权重，降低径向年轮对侧面的影响。

## 端面

端面由年轮、木射线、毛孔和径向裂纹组成。新切面可混入较暖的 `freshCut` 色。

## 结疤

结疤根据母材种子沿长度分布。结疤同时改变颜色、高度和纤维流向。

## 加工痕

`toolMarks` 控制刨削长沟与轻微斧削节奏。上漆预设降低整体凹凸强度，使漆面保持克制。

## 随机稳定性

颜色微差、纤维尺度、结疤、裂纹与粗糙度由构件派生种子控制。刷新页面或重新载入建筑时，保存的建筑总种子会恢复同一结果。
