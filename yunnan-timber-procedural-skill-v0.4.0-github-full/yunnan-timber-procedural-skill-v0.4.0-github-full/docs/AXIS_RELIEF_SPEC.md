# 坐标与凹凸规范

## 材质坐标

规范材质坐标为：

```text
X 木材长度与纤维方向
Y 截面第一径向方向
Z 截面第二径向方向
```

`canonicalTimberBasis()` 根据构件几何轴建立右手坐标系。材质采样发生在构件对象空间，构件装配、旋转与移动不会让木纹滑动。

## 圆柱校正

标准 Three.js `CylinderGeometry` 的长度轴为局部 Y。圆柱传入：

```text
geometryLengthAxis [0, 1, 0]
radialAxisHint [1, 0, 0]
profile round
```

映射结果：

```text
材质 X = 几何 Y
材质 Y = 几何 X
材质 Z = 几何负 Z
```

该关系保持右手坐标系。柱身使用圆材纵纹，端盖自动归入端面年轮。

## 圆材与方材

圆材侧面处于近似恒定半径。如果直接把径向年轮作为主要颜色，会产生横向条带。圆材分支将主成分改为沿长度延伸的纤维、结疤流线、轻微色变和加工痕。

方材侧面可保留更多径向年轮信息，用于表现弦切与径切面的变化。

## 统一高度场

程序高度由低频不平、纤维脊、年轮脊、结疤、毛孔、细裂纹和加工沟组合。

建筑观察档只使用程序微法线。

近景档增加六步视差。

构造检查档增加十步视差与最多 4.5 毫米的低频位移。默认材质强度会继续乘以预设的 `relief` 系数。

端面和榫卯切面不进行顶点位移。影响轮廓、投影或碰撞的破损需要进入构件几何。
