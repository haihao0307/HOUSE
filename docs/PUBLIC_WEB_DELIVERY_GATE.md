# Brick Mother、Tiles Mother 与建筑工作台在线交付门禁

版本：1.0.0

## 交付条件

用户以公开在线网页作为验收入口。HTML、工作台、材质实验页、建筑预览页和测试页，在真实公网地址完成回读以前，不得报告“已经上线”“可以打开”或“发布完成”。

链接属于交付成果。404、403、空白页、错误重定向、关键资源缺失、旧缓存、画布启动失败和控制台致命错误，均按发布失败处理。发现后立即重新发布并重新验证。

## 每次发布必须完成

1. 确认实际发布目录存在非空 `index.html`。
2. 确认文件已经进入实际部署分支或部署系统。
3. 从最终公开网址发起全新 HTTP 请求，跟随重定向后必须返回 200。
4. 回读正文必须包含当前版本唯一标识，并排除托管平台错误模板。
5. 回读关键脚本、数据、样式与模型依赖，任一关键资源失败时整页失败。
6. 使用真实浏览器确认画布或主要界面出现，记录页面错误、控制台致命错误和资源失败。
7. 桌面与手机分别检查。触控、WebGL、麦克风或摄像头功能继续完成对应设备检查。
8. 保存公开网址、状态码、字节数、哈希、提交 SHA、验证时间和浏览器证据。
9. 生成 `PUBLICATION_PROOF.json`。只有 `shareAllowed=true` 时才可把链接交给用户。
10. 新版公开验证完成以前保留上一版可用入口。

禁止根据仓库路径猜测网址。禁止把构建成功、本地打开成功或本地截图当作公网可用证据。禁止让用户承担首次打开和发现 404 的测试工作。
