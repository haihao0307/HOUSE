# Brick Mother workbench delivery rule

This production line delivers runnable online 3D HTML examples. Static AI-generated images, image cards, archive uploads, build status, and source staging do not constitute a workbench delivery.

The user-facing result must begin with a directly clickable, publicly reachable HTML example. The example must be opened and rendered in a real browser before claiming publication. Verify the deployed source fingerprint against the tested candidate. Do not present an old URL as a new release.

Preserve the V2.7.5 core with Git blob 7b10389cb9367f7423619262820883cc94b07a61. New presentation and material work remains additive. Work only on feature/brick-mother-v2.0-composite-material-dna. PR 15 remains open, Draft and unmerged. Human visual and production approvals remain false until explicit user acceptance.

Priorities from the user: recognizable brick, earth and stone; non-mechanical fine relief; restrained dielectric reflections; bright multi-directional studio lighting; a clean matte pedestal; responsive initial display; no hidden renderer running behind inactive workbench tabs; immersive idle view; tap-to-reveal side controls; orbit, touch zoom and pan.

Fullscreen must be triggered through an actual user gesture. Do not claim that an ordinary browser page can automatically remove the browser address bar. Standalone installed display and fullscreen support must be reported separately from successful HTML rendering.

The PBR Guide, third edition (2018), is the source for channel semantics and shading principles. Weathering coefficients, palettes, geometry choices, light setups, performance policies and interaction design are project implementations. They are not measured values supplied by that guide. Software-renderer test timings must not be advertised as hardware GPU benchmarks.
