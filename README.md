# 云南传统建筑蓝图与总体系全量知识包 V1.0.0

日期：2026年9月2日

本包是“历史建筑生产线”中建筑蓝图与总体系的当前完整交接。它用于新窗口、Codex 或后续执行者快速接续建筑研究与三维生产。

## 首先确认的职责

本线长期负责传统建筑知识、建筑蓝图、构造组织、程序化生成、三维总装、在线工作台、证据和版本维护。

本线不承接照片生成、照片修复、照片润色、宣传图制作或单纯静态出图。照片、扫描图、测绘图和历史影像只作为建筑证据输入。

面向用户的主要成果应是能够旋转、缩放、剖切和切换检查模式的完整三维建筑。研究文字、来源、推导和限制保存于知识库，不用大量文字界面代替建筑成品。
