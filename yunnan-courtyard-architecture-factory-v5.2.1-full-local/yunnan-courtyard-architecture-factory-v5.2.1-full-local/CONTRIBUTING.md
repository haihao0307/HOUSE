# 贡献与修改流程

## 分支与提交

建议从 `main` 创建短期功能分支。一次提交只处理一个明确问题，例如遮挡、门窗、楼梯、屋架或瓦作。

## 基线检查

```bash
python tools/validate.py
python tools/browser_smoke_test.py
```

## 修改原则

平面、剖面、构架和屋面保持依赖关系。任何尺寸变化需要说明来源、推导方法和置信度。任何临时视觉替代都要明确标记，不得伪装成测绘或历史定型结果。

## 拉取请求说明

请写明：

1. 修改了哪些文件。
2. 修改对应哪个建筑逻辑。
3. 使用了哪些资料。
4. 哪些验收项已经通过。
5. 尚有哪些资料缺口。
