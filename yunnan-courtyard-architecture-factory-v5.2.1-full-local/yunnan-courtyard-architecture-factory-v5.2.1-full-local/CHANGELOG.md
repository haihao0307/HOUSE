# 更新记录

## 5.4.1

1. 公开生产线新增 GitHub 同步中枢：读取仓库中的母系统、Three.js 生产合同、团结乡材料证据和最新提交。
2. 网页命令、现场观察、纠错复核和新增证据可进入本地可审计队列，并导出 `yunnan-production-web-sync-*.json`。
3. 新增可选 GitHub Issues 回传：Fine-grained token 只在当前页面内存中使用，不写入源码、localStorage 或导出文件；回传记录统一使用 `[Web Sync]` 标题，便于生产线和后续资料整理同步。
4. 404 入口与主页面统一为 V5.4.1，并保留无令牌只读访问。

## 5.4.0

1. 新增 `threejs/YunnanMaterialFactory.js`，把团结乡样本确认的风化土墙、旧木、云南板瓦—筒瓦和石基外观拆成可复用的 Three.js PBR/程序化风化材质层。
2. 新增 `threejs/YunnanCourtyardProduction.js` 与独立预览页，按滇中一颗印的平面和构架语法生成收分土墙、圆柱、门洞木作、小窗、柴屋、日常楼梯、石板地面及独立逐片瓦顶。
3. 新增生产体系合同、证据边界和 QA 记录；团结乡瓦件精确尺寸、搭接、基层和墙体成因仍保持未锁定，不把扫描 GLB 当作 BIM 构件源。
4. 生产线网页新增 Three.js 参数化生产原型入口，支持按 walls、roof-tiles、timber-frame、doors-windows、stone-and-ground 分组检查。

## 5.3.6

1. 将团结乡样本 01 高精度扫描中的长期风化土墙、典型云南板瓦—筒瓦视觉关系和旧木构综合色登记为用户确认的实物参考。
2. 新增独立材质与风化证据合同，分别记录用户确认、直接观察、专业解释、未锁定项和扫描瑕疵排除项，避免把风化误判为贴图错误或把摄影测量破边当成构造。
3. 新增三套可复用生产规则：分区式土墙风化、离散板瓦—筒瓦旧瓦面、低饱和灰褐至深褐旧木色；同时禁止连续波纹板替代、均匀噪声墙面和高饱和亮漆木材。
4. 网页“团结乡样本”页同步公开已确认的材料证据与仍待测的瓦片尺寸、搭接、基层、墙体配比、木种和涂层。

## 5.3.5

1. 新增 `YN_TUANJIE_001_EDITABLE_HIGH.glb` 高精度可编辑主档：保留原始 High 扫描的 48 个网格、608,634 个顶点、464,288 个三角面，以及 7000×7000 底色与 2500×2500 法线贴图。
