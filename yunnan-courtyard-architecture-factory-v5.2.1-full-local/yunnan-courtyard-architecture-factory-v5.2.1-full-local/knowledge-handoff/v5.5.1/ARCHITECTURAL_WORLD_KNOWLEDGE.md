# 云南民间建筑生产线的世界知识与建筑体系

## 总体认识

云南民居是地区、民族、地形、气候、材料、生活方式和历史技术共同形成的系统。生产线从平面、间架、地基、柱网、楼层和交通逐层生成，不能从外观盒子开始。

## 基本依赖链

`证据与年代 → 场地与主轴 → 院落拓扑 → 间架与柱网 → 地基墙脚 → 一层平面 → 楼面二层 → 立面等级 → 控制剖面 → 木构装配 → 独立屋面 → 瓦作 → 门窗运动 → 历史状态 → 三维装配与验收`

平面未通过时不生成立面；剖面和檩位未确定时不生成瓦面。

## 间数、开间和柱网

中国建筑以“间”为基础模数。三间正房对应四条主要开间轴线；明间和次间可以不同宽。间数决定柱网、门窗、梁架、屋脊长度和房间组织。楼层共享柱网和标高账本。

## 滇中一颗印

典型“一颗印”为“三间四耳倒八尺”。核心是正房三开间、左右耳房、入口倒座、中央天井和廊厦组成的紧凑内向院落。正房等级最高，耳房和入口依次降低。外围高墙封闭，院内木构和门窗更加开放。

## 纳西支系

一坊房、两坊拐角、三坊一照壁、四合五天井属于院落组织类型。平房、明楼、两步厦、两面厦、蛮楼、闷楼、骑厦楼属于单体或剖面类型。院落类型与单体类型不得混排。

## 独立屋面单位

正房、耳房、倒座、门楼、大厦、小厦均为独立屋面单位，各自拥有屋脊、檐口、坡向、出檐和排水目标。主体单体至少双坡；披檐和厦子可以单坡。不得把整个院落合并成一张大屋面，也不得无依据制造斜沟。

## 板瓦、筒瓦与檐口

板瓦凹面向上，沿最大坡降形成连续水槽。筒瓦凸面向上，覆盖相邻板瓦列之间的纵缝。铺设从檐口向屋脊推进，上段压住下段。板瓦列檐端接滴水，筒瓦列檐端接勾头。正脊、垂脊和封头在坡面瓦完成后单独装配。

板瓦和筒瓦数量不能简单一一相等。筒瓦对应板瓦列之间的缝，边缘收口另算。最高脊瓦必须沿两坡最高交界轴线，不能落在坡面或建筑后方。

## 历史瓦面

历史感来自烧成色、坡面朝向、日晒、积尘、水流、背阴湿度、苔藓地衣、局部沉降、崩边缺瓦和维修片区。禁止每片瓦独立随机色和机械等距阵列。檐口端部有微差，筒瓦高度和瓦列直线度有手工偏差。

## 墙体生产系统

墙面由主体土体、抹灰层、稻草或纤维夹杂、裸露土坯或夯土、石勒脚、砖包角、墙脚湿带、雨痕、剥落、裂缝和补抹组成。完整抹灰区和被雨蚀后露出的基层必须共存。

返潮由墙脚向上衰减；雨痕顺重力向下；檐下受遮蔽；洞口角和材料交界更易开裂；修补有边界和年代色差。禁止满墙高频噪声。

## 木作与门窗

门、窗、柱、枋、栏杆和门楼木作共享木材生产逻辑：木纹方向、日晒褪色、雨淋发灰、手触包浆、接地返潮、边角磨损、开裂和替换件年代差。活动门窗必须保存宿主墙、洞口、框、活动扇、转轴、开启角度和状态。

## 入户与上楼

人物路线为：门外主轴 → 大门 → 倒座门道 → 中央天井 → 小厦檐下 → 楼梯巷 → 8+8 双跑木梯 → 二层檐廊 → 二层房门。门扇随人物接近联动，人物不得穿墙、穿楼板或穿栏杆。

## 证据等级

- `measured-required`：测绘尺寸、明确节点和控制剖面。
- `semantic-component-evidence`：模型明确拆分的语义构件。
- `grouped-scanned-surface-evidence`：分组扫描模型。
- `scanned-surface-evidence`：整片扫描曲面。
- `texture-only-evidence`：只支持颜色和表面表现。
- `visual-calibration-only`：可运行视觉校准，随时可被实测替换。
- `unresolved`：证据不足，禁止伪装为事实。
