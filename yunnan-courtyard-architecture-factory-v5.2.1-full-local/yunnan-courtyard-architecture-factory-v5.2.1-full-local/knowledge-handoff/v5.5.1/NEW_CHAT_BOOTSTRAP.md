可以直接说：

> 小李工程师，继续云南民间建筑生产线。先读取 GitHub 仓库 `haihao0307/HOUSE` 的分支 `codex/yunnan-surface-production-v5.5.0`，再读取项目目录 `knowledge-handoff/v5.5.1/` 中的全部文件。严格按知识库工作，继续修正板瓦、筒瓦、正脊、出檐、山墙、墙面和木作。所有任务由你直接指挥 Codex，用户只看最终网页成果。

10. 确认上述步骤完成后再驱动 Codex。

1. 不让用户重新上传已有 GLB。
2. 不让用户复制任务给 Codex。
3. 不让用户下载、解压、重打包后再上传。
4. 不让用户处理 GitHub 分支、PR、Actions 或 Pages。

## 当前开发目标

当前版本目标为 V5.5.1 细节修正版。

重点修正：

1. 板瓦凹面向上，形成连续水槽。
2. 筒瓦覆盖相邻板瓦水槽之间的纵缝。
3. 正脊位于两坡最高交界轴线。
4. 板瓦和筒瓦形成真实出檐。
5. 山墙只位于双坡屋面两端。
6. 瓦面出现连续沉降、积尘、雨蚀、苔藓、破损和成片修补。
7. 墙面出现抹灰、稻草纤维、土坯深浅、夯筑层理、返潮、雨痕、裂缝、剥落和修补。
8. 木作出现木纹、日晒、雨淋、包浆、返潮、磨损和替换件年代差。
9. 保持活动门窗、人物入户和 8 加 8 双跑楼梯无回归。
10. 主网页只显示最新成果。

## 完成标准

1. 实际文件进入 GitHub 远端分支。
2. 浏览器专项 QA 与完整生产线回归零失败。
3. 真实截图能够显示完整建筑、瓦檐、正脊、山墙、墙面、门窗木作和人物路线。
4. 合并到 `main` 后 GitHub Pages 正常部署。
5. 最终只向用户提供最新网页入口和必要的成果截图。
