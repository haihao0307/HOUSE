## 1. 三模型证据对照

三个模型支持总览、单独观察和同步镜头。每个模型显示：

- 证据类别
- 网格、三角面、贴图规格
- 适合提取的知识
- 禁止直接推断的内容

提供镜头预设：完整外观、屋顶重点、墙面重点、入口重点、屋檐近景。

扫描曲面不能伪装成已拆分的语义瓦件或墙体构件。

## 2. 屋顶关系理解

制作独立、可旋转的参数化屋顶关系示范件，至少包含：

- 正房独立对称双坡
- 左右耳房内长外短不对称双坡
- 倒座独立双坡
- 大厦披檐
- 小厦披檐
- 门楼小屋面
- 不同屋脊和檐口标高
- 前后遮挡和院内汇水

观察模式：完整屋面群、轮廓、爆炸分层、水流、单坡隔离、标高线。

屋面可见厚度拆为：

1. 檩条与椽列
2. 椽上基层
3. 板瓦水槽
4. 筒瓦盖缝
5. 勾头与滴水
6. 正脊、垂脊和封头

禁止用一块均匀厚板代表全部屋面。

## 3. 入户与上楼关系

严格复用现有交通逻辑：

`门外主轴 → 大门自动开启 → 倒座门道 → 中央天井 → 小厦檐下 → 楼梯巷 → 8+8 级双跑木梯 → 二层大厦/檐廊 → 正房二层门开启 → 二层空间`

要求：

- 平面路线与三维人物同步。
- 人物接近门时门扇开启，离开后延迟关闭。
- 保持当前 8+8 级双跑日常木梯基线。
- 提供外部第三人称、院内跟随、人眼入户三种镜头。
- 到达楼梯和二层时可见楼板、平台、檐廊与门洞。
- 不能偷偷删除墙体或屋顶。需要观察时采用明确的半透明诊断模式。

## 4. 墙面生成工具原型

实现可操作的墙面样板生成器，至少提供：

- 滇中一颗印旧土墙
- 乌龙村旧墙参考
- 大理院落墙面参考

参数分层：

### 结构与大形

- 墙高、墙厚、收分
- 墙脚高度
- 转角保护宽度
- 门窗洞口

### 材料层

- 主体材料候选
- 抹灰覆盖率
- 裸土暴露率
- 石勒脚或砖墙脚
- 砖包角
- 粗糙度与法线强度

### 年代与风化层

- 墙脚返潮
- 垂直雨蚀
- 表层剥落
- 裂缝
- 修补斑块
- 烟熏与污渍
- 色彩冷暖和明度变化

规则：

- 大尺度材料区优先于高频噪声。
- 风化服从重力、雨水、屋檐遮蔽、墙脚湿度和修补逻辑。
- 禁止满墙随机噪声。
- 结构、材料和历史状态分层，可单独关闭和回滚。
- 参数变化实时显示，并提供结构、材质、风化三种视图。

## 5. 瓦顶生成工具原型

实现可操作的单坡、双坡瓦顶生成器，至少提供：

- 刘致平图录样本
- 三开间前廊测绘样本
- 乌龙村视觉参考
- 大理视觉参考

参数分层：

### 屋面几何

- 坡长、屋面宽度、坡度
- 檐口微曲、屋脊高度、出檐
- 可见基层厚度

### 瓦件

- 板瓦、筒瓦尺度
- 板瓦列和筒瓦盖缝列
- 勾头、滴水、正脊、封头
- 质量档

### 色彩与历史状态

- 烧成基础色
- 朝向日晒
- 积尘、苔痕、雨蚀
- 缺瓦、破损、修补瓦比例
- 修补瓦年代色差

强制关系：

- 板瓦凹面向上形成连续水槽。
- 筒瓦凸面向上覆盖板瓦列间纵缝。
- 板瓦檐端对应滴水。
- 筒瓦檐端对应勾头。
- 水流连续到檐口。
- 未解决的搭接、列中心距、基层和住宅脊部节点明确标记为 `unresolved` 或 `visual-calibration-only`。
- 三档质量共用同一构件 ID 和排水拓扑。

## 6. 证据到规则矩阵

页面新增矩阵：

`证据 → 观察 → 生成规则 → 参数 → 状态`

至少包括：

- 大理屋面群 → 多级屋脊檐口 → 独立屋面单元 → `ridgeElevationByBuildingUnit` → required
- 乌龙村法线 → 瓦面与墙皮局部凹凸 → `normalStrength` → visual-reference
- 团结乡分组 → 屋顶、一层、二层分层观察 → `buildingGroupId` → required
- 扫描外观无法证明瓦片搭接 → `longitudinalOverlap` → unresolved

让用户一眼看清哪些知识已经进入生产规则，哪些仍处于参考层。
