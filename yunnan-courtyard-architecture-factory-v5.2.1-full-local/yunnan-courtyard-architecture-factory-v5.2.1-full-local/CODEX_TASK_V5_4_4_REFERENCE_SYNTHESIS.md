# Codex 任务 V5.4.4：三模型理解校验页、入户逻辑、墙面生成器与瓦顶生成器原型

## 任务目的

用户需要通过一个新的公开网页检查上游是否真正理解最新加入的三个云南建筑参考模型，重点观察：

1. 瓦顶如何由多层、多个独立屋面单元自然组合。
2. 人从门外进入院落、经过门道与檐廊、到达楼梯并进入二层的空间逻辑。
3. 云南旧墙如何由墙体主体、表层、墙脚、转角保护、返潮、冲刷、剥落和修补共同形成。

本任务必须产出一个新网页供用户直接验收，不能只写文档或总结。

## 一、三模型证据对照

保留三个真实模型的单独查看与总览，新增“同步镜头”模式，使三个模型可以在相近俯角和距离下比较。

每个模型旁必须明确显示：

- 证据类别
- 网格与三角面数量
- 底色与法线贴图规格
- 适合提取的知识
- 禁止直接推断的内容

允许切换：

- 完整外观
- 屋顶重点
- 墙面重点
- 入口重点
- 屋檐近景

扫描曲面模型不能伪装成已经拆分的语义瓦件或墙体构件。

## 二、屋顶关系理解

制作一个独立、可旋转的参数化屋顶关系示范件。它不照抄扫描模型，而要把三个参考模型和测绘知识转换为清晰的生成逻辑。

示范件至少包含：

- 正房独立对称双坡
- 左右耳房内长外短不对称双坡
- 倒座独立双坡
- 大厦披檐
- 小厦披檐
- 门楼小屋面
- 不同屋脊和檐口标高
- 前后遮挡与院内汇水关系

必须提供：

- 完整屋面群
- 仅显示屋面轮廓
- 爆炸分层
- 顺坡水流
- 单坡隔离
- 屋脊与檐口标高线

屋面可见厚度拆为：

1. 檩条和椽列
2. 椽上基层
3. 板瓦水槽
4. 筒瓦盖缝
5. 勾头和滴水
6. 正脊、垂脊与封头

禁止用一块均匀厚板代表全部屋面。

## 三、入户与上楼关系

新页面需要清晰演示一颗印的交通链：

`门外主轴 → 大门自动开启 → 倒座门道 → 中央天井 → 小厦檐下 → 楼梯巷 → 双跑木梯 → 二层大厦/檐廊 → 正房二层门开启 → 二层空间`

要求：

- 使用现有门窗装配与人物路线逻辑，不另造互相矛盾的路线。
- 显示平面路线和三维人物同步进度。
- 人物接近门时门扇自动开启，离开后可延迟关闭。
- 楼梯必须保持当前 8+8 级双跑日常木梯基线。
- 可切换外部第三人称、院内跟随、人眼入户三种镜头。
- 人物到达楼梯与二层时必须能看见楼板、平台、檐廊和门洞关系。
- 不允许为了看路线偷偷删除整栋墙体或屋顶；需要时使用明确的半透明诊断模式。

## 四、墙面生成工具原型

实现一个可操作的墙面样板生成器，至少提供三种基础预设：

- 滇中一颗印旧土墙
- 乌龙村旧墙参考
- 大理院落墙面参考

参数层必须分开：

### 结构与大形

- 墙高
- 墙厚
- 收分
- 墙脚高度
- 转角保护宽度
- 门窗洞口

### 材料层

- 土体或砌体主体候选
- 表面抹灰覆盖率
- 裸土暴露率
- 石勒脚或砖墙脚
- 砖包角
- 粗糙度
- 法线强度

### 年代与风化层

- 墙脚返潮
- 垂直雨蚀
- 表层剥落
- 裂缝密度
- 修补斑块
- 烟熏与污渍
- 色彩冷暖和明度变化

必须遵循：

- 大尺度材料区优先于高频噪声。
- 风化服从重力、雨水、屋檐遮蔽、墙脚湿度和修补逻辑。
- 不能把随机噪声铺满整面墙。
- 结构几何、材质外观、历史状态分层，可单独关闭和回滚。
- 参数变化实时显示，并提供结构视图、材质视图和风化视图。

## 五、瓦顶生成工具原型

实现一个可操作的单坡与双坡瓦顶生成器。至少提供：

- 刘致平图录个案样本
- 三开间前廊测绘个案
- 乌龙村视觉参考
- 大理视觉参考

参数分层：

### 屋面几何

- 坡长
- 屋面宽度
- 坡度
- 檐口微曲
- 屋脊高度
- 出檐
- 可见基层厚度

### 瓦件

- 板瓦尺度
- 筒瓦尺度
- 板瓦列数
- 筒瓦盖缝列数
- 勾头和滴水
- 正脊与封头
- 质量档

### 色彩与历史状态

- 烧成基础色
- 朝向日晒
- 积尘
- 苔痕
- 雨蚀
- 缺瓦
- 破损
- 修补瓦比例
- 修补瓦年代色差

必须保持：

- 板瓦凹面向上形成连续水槽。
- 筒瓦凸面向上覆盖板瓦列间纵缝。
- 板瓦檐端对应滴水。
- 筒瓦檐端对应勾头。
- 水流能够连续到檐口。
- 未解决的搭接、列中心距、基层与住宅脊部节点标记为 `unresolved` 或 `visual-calibration-only`。
- 三档质量共用同一构件 ID 和排水拓扑。

## 六、从参考到规则的解释面板

新增“证据 → 观察 → 生成规则 → 参数 → 状态”矩阵。

示例：

- 大理屋面群 → 多级屋脊与檐口 → 独立屋面单元 → `ridgeElevationByBuildingUnit` → required
- 乌龙村法线 → 瓦面和墙皮局部凹凸 → 法线强度与高频细节 → `normalStrength` → visual-reference
- 团结乡分组 → 屋顶、一层、二层可分层观察 → 生成器分组合同 → `buildingGroupId` → required
- 扫描外观 → 看不到瓦片搭接 → 搭接参数保持锁定 → `longitudinalOverlap` → unresolved

这个矩阵需要让用户一眼看懂哪些知识已经进入生产体系，哪些还在参考层。
