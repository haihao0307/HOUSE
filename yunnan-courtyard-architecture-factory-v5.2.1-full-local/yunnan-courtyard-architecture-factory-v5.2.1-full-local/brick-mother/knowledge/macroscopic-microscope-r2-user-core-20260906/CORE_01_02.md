## 核心一，对数球坐标

原作先把三维位置改写为对数球坐标：

```math
\xi_0=\log_2(\lVert p\rVert)-2-0.3t
```

```math
\xi_1=-p_z/\lVert p\rVert
```

```math
\xi_2=\operatorname{atan}(p_x,p_y)
```

本线以后按用户本次给出的精确形式记录。`xi1` 不额外减一，`atan` 的参数顺序也不擅自交换。常数偏移会改变后续余弦的相位，因此实现、答卷和测试必须保持同一约定。

`log2(length(p))` 把距离的乘法变化转成坐标中的加法移动。距离成倍变化以后，尺度层级在同一函数空间中连续推进。镜头沿尺度方向深入时，大洞边缘能够连续展开为小洞、细孔、薄脊和更细的起伏。这种关系用于解释宏观与微观尺度之间的连续联系。

生产使用时，静态砖石以对象局部参考坐标输入，时间项默认冻结。相机只负责观察。相机位置、屏幕坐标、帧号和生成顺序不能进入材料身份。每块砖可以由稳定 brickId 派生自己的局部中心、轴、相位和有限尺度偏移，六面仍共享连续三维定义。

## 核心二，十七个尺度及其导数意义

尺度为：

`1, 2, 4, 8, ..., 65536`

共十七层。单层主体写为：

```math
C_s(\xi)=\cos\left(
\cos(s\xi_2)\cos(s\xi_0)
+\cos^2(s\xi_1)
+\cos(s\xi_1)\cos(s\xi_0)
\right)
```

组合场为各层 `C_s/s` 的前缀和。新增层时保留旧层原系数，不按总层数重新归一化已经存在的粗层。

每层数值幅度按 `1/s` 下降。对位置求导时，内部相位会带回频率因子 `s`。因此更细层对标量值的贡献可以很小，对梯度、边缘方向和法线的影响仍然明显。高频层需要独立的屏幕足迹过滤、法线强度上限和抗混叠检查。

## Brick Mother 的直接落地规则

1. R5 保持唯一视觉基线。强度 A=0 时，位置映射、颜色、粗糙度、法线和几何都必须恢复到 R5 对应对象。
2. 粗层和中层可以组织大色区、烧结区、粗糙度区域及受门控的真实孔边。细层主要贡献微法线、细粗糙度和极浅表面变化。
3. 真实大洞、断边、掉块、壳片厚度和明显凿口需要进入几何或明确的隐式场。只改变材质法线时，不得宣称轮廓、剖面或接触已经改变。
4. 同一 brickId 的十七层前缀、局部坐标和相位保持稳定。换镜头、改变创建顺序或重新加载不能改变其表面身份。
5. 每块砖可以拥有不同的稳定坐标变换参数，家族基础色、整体烧结范围和形体统计仍保持同类约束，避免个体差异变成不同材料。
6. 不使用规则白点、规则黑点、棋盘或每面单独随机制造复杂感。
7. 正式候选需要固定相机、灯光、曝光、形体和种子，比较 R5、A=0、低层前缀、完整十七层，以及真实几何门控结果。
8. 自动测试分别验证数值前缀、A=0、相机不影响身份、六面连续、屏幕抗混叠和性能。视觉真实性继续由用户决定。
