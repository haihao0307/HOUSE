# Brick Mother 2.0 下一阶段交接

V1.0 已冻结。V2.0 从 V1.0 继承材料档案、几何生成器、六层噪波、诊断通道、浏览器 QA 和在线发布结构。

## V2.0 首要目标

1. 从原始 Base Color 贴图提取灰褐基底、绿色附着、橙红骨料、白色矿物和深色孔隙的真实色簇。
2. 提取参考纹理在宏观、中观、微观三个尺度的空间频谱。
3. 让孔隙、颜色、粗糙度、微法线和 AO 共用同一事件场，增强材料内部关联。
4. 提高孔洞边缘锐度，同时保留侵蚀后的碎裂过渡。
5. 增加真实断面与外表面的材质差异。
6. 建立砖块批次、窑位、湿度、盐析、泥污和生物附着的分层系统。
7. 在单砖视觉通过后进入砌筑、错缝、灰浆、墙体批次和 LOD。

## 保护规则

V1.0 的在线入口、版本包、发布分支、QA 证据和 SHA256 保持不可变。V2.0 的实验参数不得回写 V1.0 数据文件。
