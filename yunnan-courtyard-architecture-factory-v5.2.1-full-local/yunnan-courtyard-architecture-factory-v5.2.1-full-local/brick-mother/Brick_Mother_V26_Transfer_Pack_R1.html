六层生成链

真正有效的是链条，而不是单独把某一种噪声强度拉大。

01基础形体可恢复的基础 SDF 或基础网格，所有事件关闭时必须回到原形。
02三维域扭曲先扭曲三维采样空间，再计算形体，改变真实轮廓而非只改颜色。
03连续形体场fBm、Ridged fBm、Turbulence、Strata、Micro Erosion。
04负几何事件深孔、裂缝、崩角、塌口和大侵蚀真实切除体积。
05材质关联同一事件驱动 Base Color、Roughness、Normal、AO、Wetness。
06接收方映射由接收 Mother 映射真实尺度、证据约束、性能和生产验收。

负几何事件库

黑色斑点不是洞。下列事件必须进入 SDF、体积或真实网格。

chips · 崩角

边角附近的不规则椭球切除，改变外轮廓。

fresh break + roughness + AO
pits · 浅坑

浅层椭球切除，形成细腻但可读的表面低洼。

cavity + normal + roughness
poreClusters · 孔群

同一父掩膜下聚集的多尺度小孔。

cavity + AO + dark color
deepPores · 深孔

孔口椭球 + 孔道胶囊体，不是黑色圆贴图。

deep AO + wetness + bore wall
poreRimChips · 孔缘破碎

围绕孔口再布置多枚不规则切削体。

rim normal + fresh break
collapsedPores · 塌孔

更宽、更偏斜的塌口与塌顶，破坏规则圆形。

cavity + weathering + debris edge
cracks · 裂缝

弯曲窄槽或胶囊链，方向与宽度均可变化。

wetness + AO + dark color
erosionBites · 大侵蚀

宽尺度咬缺，必须改变剖面和剪影。

weathering + fresh section
inclusionVoids · 夹杂脱落空腔

纤维、稻壳或颗粒脱落后的真实孔腔。

organic rim + AO + roughness

q = DomainWarp(p, shapeSeed) D0 = BaseSDF(q) D1 = D0 + rugged * ruggedDepth + strata * strataDepth - microErosion * microDepth D2 = max(D1, -eventSdf) // 负几何切除

事件驱动的材质通道

形体、色彩和粗糙度必须来自同一事件身份，不能各自随机。

Base Color砖红、深红、焦黑、灰烬、氧化、矿物析出和湿区。
Roughness孔腔、风化、湿润和颗粒共同调节。
HeightRugged、Micro Erosion、孔缘破碎与细颗粒。
Normal来自真实高度梯度和事件方向。
AO深孔、裂缝、塌口和内凹区增强。
Wetness流向、低位、孔腔和水痕共同控制。
Weathering暴露、侵蚀、孔缘和大咬缺联动。
Mineral暴露、流动、沉积和材料区共同控制。
BaseColor <- eventMasks + palette Roughness <- cavity + weathering + wetness Normal <- heightGradient + eventOrientation AO <- deepPore + crack + collapse Wetness <- flow + cavity + lowPosition
