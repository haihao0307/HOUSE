# Brick Mother R3.3 — 砖土墙构造剖面审查

日期：2026-09-16

## 目标

在不修改 R3.2 固定页面、不修改 R2.14.8.1 母砖、不修改 R2.1-B 材质的前提下，把四米砖土墙的关键构造关系变成可量化剖面。

入口：`Brick_Mother_Wall_4x3_R3_3_Section_Audit.html`

## 本轮实际实现

- 同屏保留 R3.2 固定三维原件。
- 新增正面逐皮、中段厚度、端部拉结、竖向接触四个审查视图。
- 逐皮滑杆可检查 1—43 皮、A/B 皮型、当前砖数、砖顶与土顶。
- 把 R3.2 连续土 SDF 包络与“非重叠物理土芯候选”同时画出。
- 明确区分用户指定、程序推导和仍未验证的构造结论。

## 关键审计结论

R3.2 的连续土 SDF 从两侧外表面名义内退 10 mm，因此在中段与每面顺砖名义重叠 100.77 mm，在端部 A 皮与每面丁砖名义重叠 230 mm。这个重叠对无缝渲染有效，但不能直接视为砖、土两个可分离的物理实体。

下一内核应保留现有视觉联合体，同时额外生成“扣除砖占位”的非重叠语义土芯，用于碰撞、质量、破损、含水和施工顺序。历史砌法、结构承载与夯实参数仍未得到可靠证据。
