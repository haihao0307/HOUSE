# Brick Mother R3.4 — 用户标注修正版

本轮直接处理用户在 R3.2 画面中标出的四类问题，不修改冻结母砖 R2.14.8.1，也不覆盖 R3.2/R3.3 历史页面。

## 已实现

1. 两个墙端：每一层都不再留下贯通的中央土槽。A 皮沿用原有两端丁砖；B 皮在左右两端各增加一块中央横砖，共 42 块。
2. 墙顶：在第 43 皮内部增加 32 块中央横砖，与原有两端丁砖共同封住顶部中央土带，不增加墙高。
3. 每砖差异：冻结母砖仍是唯一母体，墙体子砖使用确定性翻转、微幅形体响应、材质相位、烧成色与粗糙度差异；刷新后不会随机跳变。
4. 墙心：前、后、顶部与两端都由同一多尺度场真实改变 SDF，默认形体幅度 ±6.5 mm；另有“墙心显微 / 墙心近看”用于检查。
5. 抹灰：增加一块可开关的抹灰试片，具有不规则边界、约 14 mm 名义厚度和默认 ±4.5 mm 显微形体。
