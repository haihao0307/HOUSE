# 04 — Receiver Handoff

## What Brick Mother gives

- normalized parameter ranges;
- deterministic seed scheme;
- event descriptors;
- continuous field functions;
- material correlation rules;
- one locked reference preset;
- tests and failure gates.

## What Brick Mother does not give

- receiving-domain truth;
- geological placement;
- DEM editing;
- cave placement;
- physics;
- final scale;
- target runtime integration;
- user acceptance.

## Receiver integration sequence

1. Preserve the receiver's accepted base form.
2. Add a bypass and protected-region mask.
3. Map normalized Brick units to real physical units.
4. Bind receiver-owned evidence masks.
5. Integrate continuous warp/erosion first.
6. Add low-count, high-value discrete events.
7. Correlate material outputs with the same event IDs.
8. Add distance/LOD policy.
9. Produce base/transfer/combined diagnostic comparisons.
10. Run receiver-owned QA and obtain separate approval.

## Volumetric warning

A height depression cannot represent a true cave, through-hole or overhang. Those require the receiver's volumetric SDF, voxel or manifold mesh method. Brick Mother only supplies event semantics and normalized descriptors.
