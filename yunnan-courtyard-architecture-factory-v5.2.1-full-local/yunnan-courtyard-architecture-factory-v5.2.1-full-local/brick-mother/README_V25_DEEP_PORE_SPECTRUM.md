# Brick Mother V2.5 Deep Pore Spectrum

V2.5 adds deterministic multi-scale clustered pores, collapsed mouths, broken pore rims,
richer fired-clay, stone, and adobe color families, and a solo close-up mode.

Open `brick-mother-standalone-v2.5.html` directly in a WebGL2-capable browser.
The standalone file contains inline CSS, JavaScript, shaders, and material profile data.

Visual approval remains pending.
