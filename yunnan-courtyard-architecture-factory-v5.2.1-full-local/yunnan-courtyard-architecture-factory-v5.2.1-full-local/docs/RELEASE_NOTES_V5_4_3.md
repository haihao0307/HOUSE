# 云南院落历史建筑生产线 V5.4.3 发布说明

## 本版目标

V5.4.3 将大理、乌龙村和团结乡三份 GLB 纳入同一研究流程，建立从参考模型观察、证据分级、屋顶与墙体知识提取，到标准生成器可回滚校准的完整链路。

   - 4096×4096 底色贴图
   - 单一扫描网格，按 `scanned-surface-evidence` 使用

## 新增网页

### 三区三模型研究

`three-reference-study.html`

支持三个模型同时载入、同步视角、完整斜视、正背侧面、屋顶俯视、檐口和屋脊近景、同步旋转、统计、截图和研究 JSON 导出。

### 标准建筑校准对比

`threejs/yunnan-reference-calibration-demo.html`

左侧显示 5.4.2 基线标准建筑，右侧显示 V5.4.3 参考校准结果。两侧相机同步，便于检查屋面高差、可见屋面厚度、瓦色、墙色和修补层。

## 屋顶研究成果

三份模型共同支持以下参考校准规则：

1. 主房、侧房、门楼、廊厦和附属空间保留独立屋面单元。
2. 同一院落允许多个屋脊和檐口高程带。
3. 屋面视觉厚度拆分为结构支承、基层候选、铺垫层候选、板筒瓦层和檐脊收边。
4. 灰瓦综合色包含青灰、暖灰、褐灰和局部浅灰。
5. 檐口、脊部、积水区、遮蔽区和修补区使用不同老化逻辑。
6. 高等级大理塔楼或门楼的强起翘与脊饰保持建筑等级控制，不能自动用于普通住宅。

## 墙体与砖石研究成果

标准墙体显示拆分为：

1. 墙体核心
2. 可见表层
3. 石基或勒脚
4. 包角和洞口收边
5. 修补层
6. 风化层

墙面综合色使用大尺度柔和色差、细颗粒、雨痕、墙脚潮变和局部修补。现代电箱、管线、烟囱候选、植物附着和扫描破片不进入 1940 至 1945 年基础规则。

## 可回滚生成器校准

新增 `threejs/YunnanReferenceCalibrationV543.js`。

该模块在原有参数化建筑上叠加：

1. 独立屋面高度偏移
2. 0.16 m 视觉叠层厚度校准
3. 每个屋面单元的确定种子瓦色场
4. 檐口、坡面和屋脊分区
5. 少量可复现的修补瓦外观
6. 多组暖土色墙面
7. 透明修补表层
8. 证据状态、来源文件和未解项元数据

这些调整均可撤销，不覆盖原始测绘和类型数据。

## 查看器修复

修复 `TuanjieGLBViewer` 自动旋转没有接收 `requestAnimationFrame` 时间戳的问题。查看器现在同时保存模型包围盒、自动入镜相机和相机状态，并支持更大的缩放范围。

## 证据边界

继续锁定：

1. 板瓦和筒瓦精确纵向搭接
2. 瓦列中心距
3. 泥背或基层厚度与固定方式
4. 普通住宅正脊、垂脊和檐口节点
5. 大理与乌龙村真实尺度和朝向
6. 墙体内部配比与夯筑层次
7. 砖石尺寸、砂浆和修补年代
8. 屋面精确曲率和各高程带的测绘尺寸
