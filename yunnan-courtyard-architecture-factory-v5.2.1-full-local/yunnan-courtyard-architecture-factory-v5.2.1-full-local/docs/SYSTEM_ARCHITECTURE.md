# 系统架构

## 总体层级

云南院落民居母系统位于最上层。当前包含两个支系：

1. 滇中紧凑合院支系，典型类型为一颗印。
2. 滇西纳西院落支系，典型类型为三坊一照壁和四合五天井。

共享母语法包括坊房、间架、柱网、院落、廊厦、独立主屋面、围护与木构分层。

## 生产依赖

```text
证据与年代
  → 场地、主轴与地坪
  → 院落拓扑
  → 面阔间数与进深步架
  → 地基、墙脚与柱础
  → 一层平面和活动开口
  → 一层木构与围护
  → 楼面和二层
  → 立面等级和控制剖面
  → 上层木构与屋架
  → 独立屋面和廊厦
  → 瓦作和排水
  → 地方构件与历史状态
  → 三维装配和验收
```

## 运行层

`index.html` 是自包含运行文件。CSS、JavaScript、系统数据和页面使用的小型图像都已内嵌。网页不需要外部 CDN。

主显示器使用 WebGL 1.0。建筑面被拆成三角形并写入深度缓冲。结构线同样参与深度测试。Canvas 只在无法创建 WebGL 上下文时作为回退。

## 数据层

`data/system_v5_2_1.json` 保存当前总系统、阶段、质量规则、证据、显示器、开口和人物路线。

`data/components/` 保存 102 类语义构件目录。

`data/typologies/` 保存一颗印和纳西支系规则。

`data/core/` 保存生产流程和旧错误拒绝清单。

`data/evidence/` 保存本地参考资料清单和哈希。

## 门窗状态机

每个活动门窗包含：

1. 宿主墙。
2. 结构洞口。
3. 门框或窗框。
4. 活动扇。
5. 枢轴位置。
6. 开启方向。
7. 角度范围。
8. 当前状态。
9. 自动触发条件。
10. 碰撞包络。

## 人物路线

人物路线采用八个建筑交通阶段。路线同时检查平面位置和垂直标高。楼梯阶段从 0.06 米连续升至 2.73 米，最终进入正房二层候选空间。

## 显示完整性

完整外观和院内观察都保留完整建筑。诊断剖切由用户显式开启。人物登楼期间只会临时隐藏少量具名屋顶组，人工拖动后立刻恢复。
