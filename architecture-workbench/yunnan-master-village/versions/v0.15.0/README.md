# 云南一颗印 V0.15.0

主文件：Yunnan_Master_and_Village_V0.15.0.html。保留原 V0.14.0 不覆盖。

打开后默认停在“铺板收工，工人依次下楼”阶段，方便先看修改。点播放继续，或点“工人下楼”重新看这段；“从头播放”保留完整施工过程。

“成屋通行复核”固定已完成的墙体与檩椽，使用独立 62 秒时钟重放三名工人从楼面经过门、木廊、两跑楼梯到院地的路径。此时底部滑块控制复核时间。工人经过门时门会自动打开，经过低檐时会俯身。正常施工中的下楼阶段位于楼板完成之后、围护安装之前；两种展示不混淆施工先后。

“二楼门”按钮在门安装后可开合；“二楼门近景”从室内观察开口。通行期间按钮显示“通行中”，避免手动关门撞人。

“完工聚餐”跳至前院用餐。“上菜近景”可看四只熟鸡腿。需看搬桌过程时，在施工列表选择“搬桌至前院，摆凳端菜”。五只狗先在后面摇尾等食，后段再出现食盆。场景不显示宰杀。

“声景试音”通过一次点击激活浏览器音频。“村落声景”控制持续声音。“手机观影”收起工具，右上角可退出。右侧工具栏能够上下滚动。

## 源码
src/runtime_v015.js 为通行、开门、聚餐和新增检查。
src/stair_v015.js 为楼梯、实体表面和承托数据。
src/build_v015.py 从 baseline 内冻结的 V0.14.0 生成完整 HTML。执行 `python src/build_v015.py`。无需下载第三方运行资源。
qa 中包含原始状态数据和测试脚本；浏览器脚本以 /mnt/data 的本次运行布局为默认输入，需要按本地路径调整，且需要 Playwright、Chromium 和可用的显示服务器。

## 证据身份
楼梯具体尺寸、标高与轴位保留程序候选标记，未冒充 SU 实测。用户提供 PDF 第101页讨论的是庆阳旅社的楼梯；本轮将其作为构造比较，未挪用为昆明一颗印测绘数据。聚餐结局与四只鸡腿来自用户创作要求。

当前仍是三间两层正房的施工演示候选；完整院落、瓦作、耳房、全部榫卯和正式3A/历史验收仍需后续工作。
