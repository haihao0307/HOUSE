# Codex 强制执行协议

1. 先读取 GitHub 仓库中的 `AGENTS.md`、`PROJECT_STATE.md`、相关任务、知识合同、证据清单、测绘 JSON 和当前生成器。
2. 先运行现有静态验证和浏览器基线。
3. 先说明要修改的证据链和受影响构件，再写代码。
4. 任何尺寸和节点必须携带 `caseId`、`evidenceStatus` 和来源。
5. 扫描外观只能影响视觉层，不能覆盖平面、柱网、剖面和历史节点。
6. 实际实现必须提交到远端分支。GitHub 读不到文件时，任务不算完成。
7. 禁止只写说明、只做孤立原型或只提供本地提交号。
8. 主网页只展示最新成果；后台基线用于自动回归。
9. 所有改动必须维持门窗、人物路线、楼梯和三模型查看器无回归。
10. 用户只接收最终网页地址与必要的成果截图。
