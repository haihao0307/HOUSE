# 变更记录

## 0.4.0

修正标准 Y 轴圆柱的材质坐标映射。

新增 `round` 圆材轮廓分支。圆柱和圆檩侧面以纵向纤维、结疤和轻微加工痕为主，端面继续使用年轮。

降低颜色纹理对比，提高纤维、毛孔、裂纹和粗糙度的细腻度。

统一程序高度场，继续支持微法线、视差与受控低频位移。

新增 `profile` 数据字段与轮廓代码。

调整四种云南木色预设。

新增 GitHub Pages 自动发布工作流、根目录入口、提交说明和完整仓库结构。

新增圆材纵纹分支、轴向契约与无外部纹理资源测试。

## 0.3.0

加入对象空间木纹、构件独立种子、四种木色与分级凹凸实验。

## 0.2.1

加入建筑生产线接口、程序微法线、视差和受控位移。
