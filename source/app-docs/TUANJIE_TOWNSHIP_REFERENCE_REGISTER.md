## 可编辑 GLB 与网页入口

生产线现为团结乡样本 01 保存同一套扫描几何的两个可编辑档位。`assets/models/YN_TUANJIE_001_EDITABLE_HIGH.glb` 是高精度主档，保留 7000×7000 底色和 2500×2500 法线；`assets/models/YN_TUANJIE_001_EDITABLE.glb` 是网页标准档，贴图为 3072×3072 和 1024×1024。两档都保留 High 扫描的 48 个独立网格、608,634 个顶点和 464,288 个三角面，并增加稳定 ASCII 名称与“场地 / 未定细部 / 一层 / 二层 / 屋顶”五个父分组。GLB 没有动画、骨骼、morph target、相机、灯光或外部解码器依赖。

在生产线网页中点击“团结乡样本”页签，再选择“打开高精度 GLB”或“打开网页标准档”。页面不会自动下载 113.8 MB 高精度档或 45.5 MB 标准档，避免每次打开生产线都消耗带宽。查看器会应用内嵌法线贴图、各向异性过滤与高 DPI 渲染。原 FBX、原始贴图和旧 High/Lite GLB 仅保留在私有证据链，不再作为网页运行依赖。

“可编辑”在这里指可以导入 Blender 并逐网格选择、重命名、切分、重拓扑或另存；它不表示扫描分片已经是柱、梁、墙、门窗或房间等 BIM 构件。若要进入参数化生产层，仍必须先由对应平面、剖面、控制尺寸或近照把语义和尺度锁定。

## 尺度说明

当前 GLB 的包围盒约为 `3.81322 × 2.33144 × 1.39608 m`，这是转换后参考资产的展示包围盒，不是团结乡实建的测量尺寸。源 FBX 记录 `UnitScaleFactor = 100`、`OriginalUnitScaleFactor = 1`，同时 `.rsInfo` 只说明本地 Euclidean 坐标，没有大地坐标或测量控制点。因此：

- Three.js 中仍按米制加载，便于稳定显示；
- 真实建筑的长、宽、高、层高和屋面坡度全部标记为 `unverifiedNoSurveyControl`；
- 至少补一条水平实测距离、一条高度和一个方向依据后，才允许整体缩放到实建尺度。

## 可直接提取与暂时禁止

现在可以提取归一化整体轮廓、院落空腔比例、相对屋面拓扑、入口—踏步—坡地顺序；可以把长期风化土墙的分区层次、离散板瓦—筒瓦的可见铺设关系，以及低饱和灰褐至深褐旧木综合色用于材质设计和外观 QA。

现在不能把 48 个扫描分片当成柱、梁、墙、门窗或屋面构件；不能把展示包围盒当实测尺寸；不能从其他云南建筑直接复制板瓦、筒瓦、柱网、楼梯或房间数据；不能从颜色猜定土料配比、风化成因、木种或涂层；不能补画扫描中没有证据的内部空间和装饰。

## 材质与构造视觉基准

1. **长期风化土墙**：以暖红褐土色为主体，保留粗颗粒暴露、圆钝侵蚀、浅灰白斑块、深色流挂或遮蔽区和石基过渡。制作时按受雨、受晒、檐下、墙脚、洞口和转角组织大尺度分区，不能用均匀噪声覆盖全墙。
2. **云南板瓦—筒瓦**：近看必须读成一片一片的离散陶瓦，板瓦居下形成排水槽，筒瓦覆盖相邻板瓦接缝，并呈现顺坡逐片搭接和檐口圆弧端头。连续波纹板、金属瓦或从脊到檐不分片的整根凸肋均判为不合格。
3. **旧木综合色**：以低饱和灰褐至深褐为准，表面偏哑光，并按日晒、遮蔽、端头、积尘和替换构件形成差别；不允许整栋统一为高饱和橙红或亮漆新木。
4. **证据边界**：浅色墙斑的具体成因、瓦件尺寸与搭接量、屋面基层、木种和原始涂层尚未确认。扫描孔洞、拉丝尖刺、漂浮碎片和贴图接缝不进入构造规则。

## 后续资料进入方式

每次增加团结乡建筑时，优先补齐以下内容：

1. 原始文件、拍摄或测绘来源与版权边界。
2. 正、背、左、右、俯视和院内人眼视角。
3. 至少两条实测控制尺寸与方向信息。
4. 平面、立面、剖面、屋面、入口和场地的独立证据。
5. 能辨认瓦作、檐口、墙基、门窗和木构的近照。

这套登记方式让后续样本既能独立使用，也能逐步形成团结乡内部的比较谱系；地区共性可以归纳，但任何精确几何仍必须回到对应样本的证据。
