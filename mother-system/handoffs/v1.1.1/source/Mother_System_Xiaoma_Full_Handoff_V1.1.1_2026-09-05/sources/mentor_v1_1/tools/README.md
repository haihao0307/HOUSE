# 工具说明

用户只需转交整个 ZIP，不需要运行脚本。小妈可直接阅读包内两份入口文档。

`verify_handoff.py` 是本包的独立完整性检查脚本，使用 Python 标准库。它读取本包文件，不依赖原电脑的 `G:` 或 `C:` 路径，不修改生产项目，不访问网络。

```powershell
python tools/verify_handoff.py
```

检查目录清单、文件 SHA256、原研究包 CRC 和原文副本一致性。通过只表示交付完整，不表示研究建议或 Mother 系统已经验证成功。

`refine_review.py` 和 `assemble_handoff.py` 保存本次修订和组包过程。修订脚本不是可重复任意执行的数据迁移器，不需要在接收端运行。

`details/tools/` 中的首轮脚本按当时环境保存，可能引用原电脑的来源路径。它们用于保留首轮分析过程；接收端无需运行它们才能阅读或验证本包。原 ZIP 已随包保存。
