# Source Map

This list is not a claim that every source is equally authoritative.
It records known places to study.

## High-priority procedural / generative sources

### SideFX / Houdini
- https://www.sidefx.com/docs/
- https://www.sidefx.com/
- Uploaded: Houdini Foundations 19.5

Primary study:
procedural networks, geometry, attributes, simulation, fields, terrain, digital assets, PDG, USD, animation.

### Gaea / QuadSpinner
- https://github.com/QuadSpinner/Gaea-Docs
- https://docs.quadspinner.com/
- https://tal-tech.github.io/gaea-doc/
- https://docs.zaovu.com/gaea/

Primary study:
terrain morphology, erosion, landform layering, masks, procedural terrain relationships.

### Adobe Substance 3D Designer
- https://www.adobe.com/products/substance3d/apps/designer.html

Primary study:
procedural materials, material graphs, surface decomposition, non-destructive material logic.

### Unreal Engine
- https://dev.epicgames.com/documentation/unreal-engine/unreal-engine-5-8-documentation
- https://www.unrealengine.com/previous-versions/documentation

Primary study:
world staging, lighting, atmosphere, real-time rendering, spatial generation relationships, large worlds, procedural content.

### Blender
- https://docs.blender.org/
- https://docs.blender.org/manual/en/3.4/
- https://developer.blender.org/docs/

Primary study:
open 3D data model, geometry, modifiers, geometry nodes, rigging, animation, API, interchange.

### INSYDIUM / X-Particles
- https://docs.insydium.ltd/
- https://docs.insydium.ltd/blender/
- http://docs.x-particles.net/

Primary study:
particles, fields, fluids, solver relationships, emergent motion.

### Three.js
- https://threejs.org/docs/
- https://threejs.org/manual/

Primary study:
lightweight runtime, scene graph, browser rendering, animation, WebGPU-oriented interactive world delivery.

## Low-priority external phenomenon records

### Meshy
- https://github.com/meshy-dev/Meshy-guide

Keep only as evidence that rapid rough 3D estimation from text/images exists.

Do not integrate into production data flow.

### Tripo
- https://github.com/api-evangelist/tripo-ai

Keep only as external reference to current rapid 3D generation capability.

Do not integrate into production data flow.

## World evidence sources

### ASF / Alaska Satellite Facility
- https://search.asf.alaska.edu/#/?maxResults=250

Study:
SAR, radar remote sensing, surface change, terrain and environmental observation.

### USGS EarthExplorer
- https://earthexplorer.usgs.gov/

Study:
satellite imagery, aerial photography, historical geospatial evidence, elevation and land-cover datasets.

### OpenStreetMap
- https://www.openstreetmap.org/#map=5/38.01/-95.84

Study:
roads, water, buildings, place names, open spatial relationships.
Always distinguish modern OSM state from historical reconstruction.

## Historical source example

### HyperWar / CBI
- https://www.ibiblio.org/hyperwar/USA/USA-CBI-Time/USA-CBI-Time-9.html

Study:
historical operational context, wartime source references, chronology, places and events.
