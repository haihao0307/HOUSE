# Open World Knowledge Commons

## 1. Open participation

The world should allow regional and domain experts to contribute knowledge.

Examples:
- Yunnan contributor provides Yunnan architecture.
- Sichuan contributor provides Sichuan architecture.
- European contributors provide local European building knowledge.
- American contributors provide regional American knowledge.
- Local craftspeople provide disappearing construction techniques.
- Historians provide archival context.
- ecologists provide local species knowledge.

The common framework is shared.
The regional knowledge is contributed.

## 2. Why this matters

Traditional knowledge is disappearing.

A major risk is that:
- authentic techniques die with practitioners,
- internet summaries repeat incorrect information,
- tourist reconstructions replace historical reality,
- simplified visual stereotypes become accepted as truth.

The system should preserve original knowledge before it disappears.

## 3. Provenance chain

Every important claim should preserve:

- contributor
- source
- date
- place
- evidence type
- photo / scan / archive / oral history / measurement / map / satellite / object
- confidence
- conflicting evidence
- reviewer
- transformation history

Knowledge may be compressed.
Provenance must remain recoverable.

## 4. World objects as knowledge containers

A digital object should not be only a mesh.

A historical building object may contain:
- coordinates,
- era,
- construction system,
- materials,
- local climate,
- repair history,
- human use,
- historical photos,
- oral accounts,
- archive references,
- dimensions,
- confidence,
- variants,
- uncertainty,
- generated geometry,
- generated material model.

The rendered object is only one visible expression of the knowledge.

## 5. Evidence layers

Potential evidence sources include:

- local human knowledge
- field measurement
- historical photographs
- historical documents
- archives
- university collections
- military archives
- museum collections
- satellite observation
- radar
- aerial imagery
- DEM
- maps
- OSM
- geological data
- climate data
- biological records
- object scans

## 6. Shared reconstruction

A future public workflow may look like:

real place + historical time
→ evidence collection
→ source reconciliation
→ knowledge graph
→ procedural reconstruction
→ interactive world
→ public experience
→ expert correction
→ new evidence
→ updated world

The public world becomes both a game and a living historical knowledge interface.
