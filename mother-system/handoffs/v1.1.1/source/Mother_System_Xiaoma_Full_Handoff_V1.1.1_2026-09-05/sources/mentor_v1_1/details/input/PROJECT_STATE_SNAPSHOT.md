# Project State Snapshot

## Current strategic direction

The project is moving away from isolated generation tasks toward a shared learning system.

The most important current bottlenecks are:
- visual judgment,
- structural observation,
- shape distillation,
- knowledge memory,
- hallucination control,
- regression prevention,
- reusable public technical knowledge,
- evidence provenance,
- cross-Mother learning.

## Current production families

1. DEM / terrain / weather / ocean
2. architecture / materials
3. aircraft / weapons / future transport
4. living systems
5. AI brain
6. historical public world

## Current mentor strategy

Astra is treated as a periodic high-level mentor.

The desired first mentor session should:
- read the whole system,
- critique assumptions,
- propose architecture,
- build a resource map,
- improve the learning loop,
- define memory and provenance,
- propose measurable roadmap,
- return a standardized package for Xiao Ma.

## Current knowledge-source policy

Study mature professional systems deeply.

Extract:
- relationships,
- abstractions,
- causal models,
- dependency logic,
- validation logic.

Do not inherit product UI or product framework by default.

## Current public-world idea

A shared historical world, potentially game-shaped, where:
- people can enter,
- people can contribute local knowledge,
- regional knowledge can be preserved,
- historical worlds can be reconstructed,
- generated objects are backed by evidence and provenance,
- the experience supports continued technical development.
